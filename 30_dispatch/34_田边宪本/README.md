# A 包 · 田边宪本条目比对

> **发给承接人只需 `45_派发包_A_田边宪本条目比对.zip`（约 56 MB）。**
> 解压即用，从 `任务书.md` 开始读。

## 这包要解决什么

一份日本写本《傷寒論》72 叶，此前从未入栏。
书手自署「田邊憲」，末叶跋署**天保四年歲次癸巳正月**（1833，清道光十三年），
书手二人：中川故謹建、田邊憲。正文末作「傷寒論畢」。

要决定它能否在页面上独立成一栏，只有一条硬指标：**它覆盖宋本 398 条里的多少条**。
另加一条只看一次的硬指标：**行款**——若合「一丁十六行、行十五字」，它就在康平本系统里；
不合，就只是另一部日本写本。

## 为什么先转正片

原件是**缩微负片**（白字黑底），直接看极易误判笔画。已在准备阶段统一 `-negate` 转为正片，
并逐页校验负片残留为 0。PDF 里的就是正片。

## 为什么要给 398 条表

承接人的任务不是「读完全书」，而是「给每一页标上条号区间」。
398 条表就是坐标系，没有它这一步无从下手。

## 自检覆盖

行数 / 页号连续 / 字段非空 / 条号范围 / 首条≤末条 / 可信度取值 / 页号重复 —— 七项硬检查。
另有：首句能否在宋本里回溯（二元组覆盖率）、相邻页条号是否衔接、「未定」占比是否过高。

实测：一份故意写错的样本被拦下 8 处（条号 999、首句空、可信度「疑似」、首条>末条、页号格式错、缺页…）。

## 打包注意（给发包方）

- 用 Python `zipfile` 打包（`00_公共地基/引擎/mkzip.py`），不要用 `zip` 命令——后者中文名乱码。
- 目录项 `external_attr = (0o40755 << 16) | 0x10`，否则解压后只读。
- 打完用全新目录解压一次，独立跑 `工具/自检.py`，确认自足。
