# B 包 · 康平本源流建档

> 发给承接人只需 **`46_派发包_B_康平源流建档_机械.zip`**（约 3.3 MB），解压即用。
> 承接人从 `任务书.md` 开始读。

## 这包要解决什么

项目现在用的「康平本」栏，转录自李顺保《伤寒论版本大全》。
但**这本书本身怎么来的**，目前只散在几段序跋里，靠人记。

已经出过一次事：项目内部长期把复刻者写作「大冢敬节」，而原书铅字印的是「大家敬节」
（通行写法应为「大塚敬節」）。一个字之差，传到下一代就查不回来。

这包要把「谁、哪年、对这本书做了什么」逐环钉死，每句话都指得回原文。

## 这包的特别之处：引文可机器验证

自检脚本会把每条 `依据.原文` 拿去素材文件里做**字符级查证**（忽略标点、空白、上标序号）。

所以：
- 编造一句「康平三年丹波雅忠手钞于京都」→ 立刻报「查不到」
- 引用包外的材料 → 报「不是本包素材」
- 只引两个字糊弄 → 报「原文太短」

这是本项目第一次把「不许臆造」这条硬规矩做成了可执行的检查。

实测：一份掺了 4 处假引文的交付被全部拦下（编造句、包外出处、3 字引文、校记空值）。

## 为什么素材里保留了错字

`01_版本大全_康平本卷首.md` 是**原文照录**，一个字未改。
原书铅字把「大塚敬節」排成「大家敬节」，这份素材里也还是「大家敬节」。

任务要求承接人：**照录原文 + 另写校记**，不许直接改。
这是本项目的核心做法——原文与校记分离，任何时候都能回到原样。
