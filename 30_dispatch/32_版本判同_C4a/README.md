# C4a 版本判同 · 派发包

> 发给承接人只需 **`44_派发包_版本判同_C4a.zip`**（8.7 MB），解压即用。
> 承接人从 `任务书.md` 开始读。

## 这包要解决什么

`_待验/` 里有 5 件「与已收录版本同名、但自己声称形态不同」的嫌疑件。
判出「确是另一版」→ 项目新增一栏原文；判出「同一版」→ 不必重复录入。

**这是当前唯一能直接影响页面的工作**（其余台账类不动页面）。

## 为什么要盲判

原文件名会直接泄露答案——实测有件名写着「明·万历二十九年赵开美刻」「简体版」
「1947 友助医学社」。照着名字填等于没判，且会漏掉最要紧的那类错：
**名字说是古刻、实物是现代电子本**。

所以：
- 判读页目录改成纯编号 `C4a-001` … `C4a-005`
- `清单.csv` 只给编号与页数，**不给文件名**
- 真实编号对应表留在项目内 `_盲码对应表_不发包.md`，**不进 zip**
- 自检脚本会拒绝「依据里出现文件名」的交付

## 包内容

```
任务书.md              任务说明、四步判法、验收标准
数据/清单.csv           5 件编号 + 判读页数
数据/已收录版本.md      项目 14 版著录 + 判同版四条判据
数据/判读页/C4a-00X/    每件 10 页，共 50 页（已压至 1600px）
交付/模板.json          照填
交付/交付格式.md        字段说明与三条不许
工具/自检.py            八项检查，交付前必跑
```

## 自检覆盖

条数 / 编号 / 必填字段 / 判定取值 / 载体取值 / 依据≥2项 / 页号真实存在 / 无文件名引用。

实测：一份故意写错的交付被拦下 7 处（含「疑似同版」这种自创判定、p999 不存在页）。

## 打包注意（给发包方）

- 用 Python `zipfile` 打包，**不要用 `zip` 命令**——后者中文名会乱码。
- 目录项须设 `external_attr = (0o40755 << 16) | 0x10`，否则解压后只读、无法填交付。
- 打完用全新目录解压一次，独立跑 `工具/自检.py`，确认自足。
