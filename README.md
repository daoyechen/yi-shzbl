# 《伤寒杂病论》多版本对照

![zones](https://img.shields.io/badge/zones-SH%20%2F%20JG-8a6d3b) ![status](https://img.shields.io/badge/status-WIP-d97706)

> 不是做电子书，是建一套**可逐条对照的坐标体系**：把不同版本的同一条文对齐到同一格，让差异一眼可见。
> 当前交付是**一个 HTML**：`index.html`（唯一交付入口，持续更新，不锁版本号），顶部切换《伤寒论》(SH) /《金匮要略》(JG)。

**[打开对照页](index.html)** · [统计资料](#统计资料) · [贡献者](#贡献者) · [已知缺口](#已知缺口)

## 当前对比版

| 项 | 说明 |
| --- | --- |
| 交付物 | [`index.html`](index.html) — 自包含单文件，离线双击即用，也是仓库首页 |
| 更新方式 | **持续重建**：工序推进后重新生成同一文件；不绑定版本名，内容一律以 `index.html` 当前状态为准，版本演进记在 `CHANGES.md` |
| 当前快照 | v0.13.0（2026-11-13，约 3.9 MB），已适配手机竖屏（≤820px 抽屉式目录） |
| 结构 | 顶部 SH / JG 双区切换，**两套独立编号空间**：`SH-1` ≠ `JG-1`，不能同号对接 |
| 骨架底本 | SH：宋本《伤寒论》**398 条**；JG：赵开美本《金匮要略方论》**465 条 / 24 篇 / 1316 段** |
| 读法 | 一条一格、各版原文并列；异文以【】标出；支持全文搜索、按篇/条号跳转、`#条号` 深链、按版本筛选、只看差异 |
| 配套产物 | 两区各 12 件总装文件：`34_总装产出_v0.12.0/`（SH）、`35_总装产出_金匮_v0.1.0/`（JG）；人读主文件 `02_条文对照本.md`，机器主数据 `01_条文总表.json` |
| 完成度 | SH 侧完成（12 件产出与基线逐字节一致）；JG 侧骨架、5 个版本包、总装、双区页已打通，**异文对齐等工序未做，整本未完成** |

> 骨架只读。改骨架 = 已交付的全部产物作废，必须全量重跑。
> 页面里的 `各版原文/*.md` 是骨架逐段渲染件，不是可对齐的原文；做段级/条级对齐请用 `金匮裁定源/` 的核定表与条级参照系。

### 数据链路

```
00_公共地基/  骨架 + 引擎 shjkit + SH 9 版包 + JG 5 版包 + 金匮裁定源
      │  assemble
      ├──> 34_总装产出_v0.12.0/        (SH, 12 件)
      └──> 35_总装产出_金匮_v0.1.0/   (JG, 12 件 + 缺口说明)
                │  htmlbuild --zones
                └──> index.html        (双区对照，单文件；持续更新，唯一交付入口)
```

- **俞桥原 md 是残卷**：仅 9,831 字（全书约 4 万），现靠段级核定表撑到 454 条，缺段无源。
- **医统正文含私用区缺字**（U+FF000 区）：页面显示为方框，原件如此，未替换、未臆补。
- **389 / 397 条界差异属底本差异**（赵开美本 vs 人卫 1964），不是错误。

逐项数字来源与「无」的四种含义，见 `35_总装产出_金匮_v0.1.0/11_数据来源与缺口.md`；进度与已定结论见 [`CHANGES.md`](CHANGES.md)。
