# 10_material · 物料

**实体都在 NAS，本地只留指针。** 这一层不占空间，只回答"东西在哪"。

## 两个入口

| 目录 | 用途 | 入库 |
|---|---|---|
| `11_inbox/` | 唯一入口。没分的东西先扔这，**常态为空** | 否 |
| `12_screening/` | 待验区筛选记录：哪些留、哪些删、为什么 | **是** |
| `15_catalog/` | 物料目录：220 件台账＋身份鉴定＋判同＋分级 | **是** |
| `19_nas` | 软链 → `/Volumes/<卷>/学习/02医/伤寒杂病论/n` | 否 |

## 入库规则：不能确证同一份，就保留（硬规矩 24）

判「重复」只认一条硬标准：**文件名相同 ＋ 字节哈希相同**。

| 情形 | 判 | 动作 |
|---|---|---|
| 同名＋同大小＋同哈希 | 确证同一份 | 不传；本地可删 |
| 同名＋同大小＋哈希不同 | 不同版本 | 两份都留，NAS 各存一份 |
| 同名＋不同大小 | 不同版本 | 两份都留 |
| 不同名，疑似同书 | 不能确证 | 都留，文件名补版本标识 |

SMB 上读整本很慢，折中：先比大小（不同直接判不同版本）；大小相同再抽头、尾、中各 64 K 的哈希。

## 两个坑

- **SMB 会改文件名编码**（NFC→NFD，`ェンタプラィズ` 变 `ェンタプラィズ`）。校验要比大小／哈希，不能只比名字。
- **SMB 不支持废纸篓**，命令行删不掉 NAS 上的文件，只能在 Finder 里删。

不入库。`19_nas` 软链换机器要重建（`ln -sfn <NAS路径> 19_nas`）。
