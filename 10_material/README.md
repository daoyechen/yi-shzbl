# 10_material · 物料

**书库实体以 NAS 留存为主，本地只留当前工作集、账本和来源指针。** 是否已有、是否处理过，以实体哈希和处理记录判断，不按目录名推断。

## 入口与书库边界

| 目录 | 用途 | 入库 |
|---|---|---|
| `11_inbox/` | 唯一入口。未分物料先登记，常态为空 | 否 |
| `12_screening/` | 筛选记录：保留、排除、未决及依据 | **是** |
| `15_catalog/` | 物料账本：文件事实、身份、判同、分级和处理索引 | **是** |
| `_待验` | 书库入口别名，和 `19_nas` 指向同一个 NAS 根；不是本地副本 | 否 |
| `19_nas` | 书库入口别名，和 `_待验` 指向同一个 NAS 根；不是本地副本 | 否 |

`_待验` 与 `19_nas` 不重复扫描、不重复登记。删除这两个软链指向的文件就是删除 NAS 实体，不按本地缓存清理处理。获准核查时只读跟随一个登记根，别名只保留来源关系。

## 内容身份、版本关系与处理复用

文件名、NAS 位置、MD5、大小和来源独立留档；完整 SHA256 标识文件内容。不能把文件名相同、大小相同或抽样哈希一致直接写成“同一份”。抽样哈希只做预筛，最终判定使用完整 SHA256。

| 情形 | 处理 |
|---|---|
| 同内容、不同名称 | 登记为同一内容的不同来源；改名不重复处理 |
| 同名同大小、完整哈希不同 | 保留两份，不能直接断言异版 |
| 不同名、内容近似 | 维持各自实体和关系；只复用有核定页映射的部分 |
| 本地副本与 NAS 实体 | 只有完整核验 NAS 已留存、无独立证据和无活动任务时，才列本地清理候选 |

具体账本字段、处理键和缓存候选由独立技能 `classical-book-vault` 管；本文件不授权扫描、搬移或删除 NAS。

## 两个坑

- **SMB 会改文件名编码**（NFC→NFD，`ェンタプラィズ` 变 `ェンタプラィズ`）。校验要比大小／哈希，不能只比名字。
- **SMB 不支持废纸篓**，命令行删不掉 NAS 上的文件，只能在 Finder 里删。

不入库。`19_nas` 软链换机器要重建（`ln -sfn <NAS路径> 19_nas`）。
