## 三、两包共用的硬规矩

1. **不臆造。** 判不了写「无法判定 / 未决」，写清缺什么；不许用「大概」「应该是」。
2. **每条依据带页号。** 页号指判读页的 `pNNN` 或原书页；写「看到什么」，不写「应该是某本」。
3. **不改原件。** 只读；交付只放 `交付/`。
4. **影印 ≠ 原刻，电子本 ≠ 实体。** 著录照实写「影印某本」「现代排印」。
5. **不转录、不校勘、不补字。** 认不出写「仅可辨…」。

## 四、包内统一结构

```
<包名>/
├── 任务书.md          ← 先看这份
├── 数据/              ← 判读材料（H03 全本影印；H04 判读页 + 非 PDF 全本 + 参考表）
├── 工具/自检.py       ← 交回前跑一次
└── 交付/              ← 交付格式 + 空目录
```

## 五、验收方式

1. 跑 `工具/自检.py`，`✓` 才收。
2. 抽验 10%：回查判读页/原书页，错 3 件以上整包退回。
3. 判定与已有结论冲突的（如 D1/D2、L9），以**已有验真结论**为准，接包人要说明为什么不同。
4. 验收报告写在 `39_派发包_待验区/验收/`（回传后建）。
