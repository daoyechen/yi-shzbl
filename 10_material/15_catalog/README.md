# 版本档案（L3 台账 + L1 收益判定）

> 逐件给 `_待验/` 的 37 件写版本身份：**是什么版本、谁注、谁刻、哪家藏、载体形态**。
> 判定依据一律来自判读页目视，页号可回溯。**只登记与定性，不转录、不校勘、不排优劣。**

## 一、为什么做这个

问题：件名靠文件名，同名不同版、现代排印混作古刻、丛书零本被当单行本。
**光看名称对不上**——本档案就是补上「身份」这一层。

两层收益，必须分开说（按 skill 的收益四层）：

| 产出 | 层级 | 页面会变吗 |
|---|---|---|
| `01_台账/清单.csv`（220 件盘实） | L4 素材整备 | 不变 |
| `C2_witness.json`（24 件身份档案） | L3 台账 | 不变 |
| **`C4a_异刻.json`（5 件判同版）** | **L1 / L2** | **判出「确是另一版」即新增一栏** |
| `C5_分级.json`（108 件电子本） | L4 风控 | 不变，但防「拿错字本当底本」 |

| C4a-005 | 伤寒论注十人书—注解伤寒论 | 中国中医药出版社**现代点校本** | **有点校者权利，不作版本** | 版权页、横排简体、有校注体例 |

**关键的三个判定原则**（本轮实地验证）：

1. **文件名不可信。** C4a-002 名字写「明万历赵开美刻」，实际是带网页水印的横排简体电子本。
   若照名入库，等于给宋本骨架塞了一个假 witness。
2. **丛书影印 ≠ 原刻。** C4a-004 只能写「影印某本」，不能写「某刻本」。
3. **现代点校本不是版本。** 有点校者的整理成果，属参考书目，不新增经文栏。
4. **一个字的误读能造出一个不存在的刻坊。** C4a-001 的题签曾被读成「田邊書院完」，
   据此著录为「天保年間田邊書院刊」。放大复核：实作「傷寒論／田邊憲書／完」，
   「憲」误认作「書」、「書」误认作「院」。**日本并无「田邊書院」**。
   2026-11-18 已修正题名/刊刻/载体/行款四项，两份档案均留 `修正记录`。
   教训：**载体一栏判错，会连带虚构出版者**；只能靠放大题签发现，缩略图上看不出来。

| 形态 | 件数 |
|---|---:|
| 原件翻拍（含稿本/钞本/活字） | 12 |

静嘉堂、央图那批都属翻拍，不是商业影印。

## 四、C5 电子文本：伪书与错字版甄别

108 件（epub 28 / txt 69 / doc 7 / mobi 2 / docx 1 / pdf 1）。实测分级：**A 19、B 78、C 1、U 10**。
**不做完整判定**（不做 OCR、不校对），只做**准入分级**：

| 级 | 判据 | 用途 |
|---|---|---|
| A 可用作参照 | 有明确底本著录、编纂规范 | 可作旁证 |
| B 需人工抽验 | 有底本著录但无版本信息，或繁简混排 | 抽验后用 |
| C 不得当底本 | 无底本声明 **且有 HTML 残留**（爬取件） | **只作线索，不作底本** |
| U 无法机器判定 | PDF/doc/mobi 不支持直读，或编码读不通 | 需另判 |

判据用三项自动检测 + 人工抽验：
- 首 200 字是否含底本/来源声明
- 简繁对应字混用率（超阈值打标）
- 是否含 HTML 残留、乱码、章节缺号
