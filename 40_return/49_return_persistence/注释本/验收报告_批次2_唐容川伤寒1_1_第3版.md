## 二、两个裁定

### 裁定一：经文**不剥离**，接受你的口径

**接受，不用做 `原文剥离.md`。** 理由三条：

1. **串讲体的经文与注文语法粘连。** 「太陽病，當惡寒發熱。今吐傷中氣……」——剥掉前半，后半是断头句。强行切会像你说的那样误删字，比冗余坏得多。
2. **L2 的用途是对照阅读。** L1 那一格已经有原文，注文里再出现一遍原文，读者正好知道这段注在讲哪句。前例已有：郝万山、胡希恕两份讲稿的 `text` 同样把引的原文留在里面。
3. **你这个做法让字符守恒更简单**，不用在 87+40 之外再维护一个「经文」维度。

**但要加三个条件**，防止「剔除」变成垃圾桶：

1. **剔除项必须分项**，不许写成一个总数。现在写「剔除（署名/书眉/脚注/经文残留/页锚点）44」——五项混一个数，等于没交代。
   改成：

   ```markdown
   | 项目 | 汉字 |
   |---|---:|
   | notes 正文 | 21,963 |
   | 经文（随浅注保留于 notes，未单列） | 0 |
   | 剔除·署名块 | 0 |
   | 剔除·书眉 | 0 |
   | 剔除·整理者脚注 | 0 |
   | 剔除·页锚点 | 44 |
   | 剔除·篇题 | 7 |
   | 未归条但已说明 | 0 |
   ```

2. **`剔除` 每项都要能在转录全文里指认**（逐条列页码，或给正则）。页锚点这种可以只给条数。
3. **`剔除` 总量超过转录 2% 就要单独说明**。你这批是 44/60 字（0.2%），很正常——说明转录全文本身已经洗干净，署名块和书眉是在转录阶段删的，不是在 notes 里。这点你做得对，继续保持。

### 裁定二：篇题「辨太陽病脈證篇」**剔除**

- 它不是注文，是篇题。**L2 只放注文**，篇名由 L1 骨架提供，重复放会让同一格出现两遍「辨太陽病脈證篇」。
- 计入 `剔除·篇题`，n=1 其余 seg 重排为 1–5（保持连续）。
- **批2 同样处理**：n=120 开头也有 `辨太陽病脈證篇`，而且后面还拖着一截旧残渣 `也：`。两个都删。

**注意：不要整段改成上一段的 attr。** 我核了原页，一段页首续文里常常前几十字是唐容川收句、后面就转回陈修园浅注。

**实例（批1 n=1 seg6，已回原页核过）**：

```
…此非太陽中風而｜名之曰傷寒。其名爲傷奈何？以膚表第一層而受損傷也。｜此論寒傷太陽之膚表。受業薛步雲：按寒陰邪也…
        ↑ 唐容川「正曰」在此收句                    ↑ 此处起转回陈修园浅注
```

所以这一段要切成两条：前 33 字（`名之曰傷寒…受損傷也。`）归 `唐容川`，其余归 `陈修园`。

**判界线的标志**（三个都好用）：

- `此論……`、`此一節言……`、`此二節……`、`此下總論……` —— 陈修园浅注的总述句，从这里起转回他
- `受業××云/按`、`男××按` —— 陈修园门人，属陈系
- 出现「西醫」「油膜」「連網」「三焦」这类唐容川独有的词，通常还在他的话里

每段切完在 `处理日志` 记一行：`条N segM 前X字归唐容川，余归陈修园，界在「此論寒傷太陽之膚表」`。
