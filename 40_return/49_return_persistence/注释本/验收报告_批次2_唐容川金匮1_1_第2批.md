### 1. p47（书页407）整页没转繁，77 个简体字

这一页是**附方段**（古今錄驗續命湯、千金三黃湯、近效白朮湯、崔氏八味丸、千金越婢加術湯），整段是简体：

```
崔氏八味丸 治脚气上人，少腹不仁。即肾气丸。
干地黃八两 山茱萸 山药各四两 泽泻 茯苓 牡丹皮各三两 …
上八味末之，炼蜜丸梧子大 …
按：汉之一两，今之三钱零。… 计今之法码，重应一两 …
千金越婢加术汤 治内热极，则身体津脱，腠理开，汗大泄，厉风气，下焦脚弱。
麻黃六两 石膏半斤 甘草二两 生姜三两 白术四两 大枣十二枚
上六味 … 纳诸药，煮取三升，分温三服。恶风加附子一枚。
【元犀按】方中术甘姜枣，所以维正气之根，不让阳随汗出，阴随热化也。
```

问题不止没转繁：**剂量单位写「两」不是「兩」，「山药」应为「山藥」，「脚气上人」应为「脚气上入」，「术甘姜枣」应为「朮甘薑棗」，「方中术」应为「方中朮」**。这一段像是从简体电子本整段粘进来的，没有过管线。

全批正文简体残留 **96 字 / 44 种**，其中 p47 一页 77 字，其余散在 p30/32/33/34/39/44/45/46/49/50 各 1–3 字。
