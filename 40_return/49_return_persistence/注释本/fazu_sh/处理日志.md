## 二、没做什么

1. **未对原书影印逐字校录**。本书电子文本本身即任越庵手钞《伤寒论翼》的系统（源文件 GBK，包内转码），本次只做结构化挂条，未做版本校勘、未补字、未改字。
2. **未逐句剥离全部引文**。卷上「风寒辨惑第四」「温暑指归第五」等篇为比较论证体，原文多先整引一条再作「以二症相较」式案语，引文与案语交织；为保语义完整，段内保留了少量被称引的经文句，未逐句剔除。凡整段为注家议论者均已排除引文（如全论大法第一 n=3 段）。
3. **未核原书缺字**。原文以「KT KT」「HT 」及空格代替缺字（如「项背强KT KT 」「任HT 鸿波」），另有「语」（谵语省字）等，均照原样保留，未补未改。
4. **未处理非正文**：序一篇（陶观永序）、书名／作者／朝代／年份四行著录、各篇 `<目录>` 行，均未收进 notes，另列于 `挂不上清单.md`。
