## 2 承接人自己没说的两件事，都对，而且都关键

### 2.1 双栏排版，确认无误

我渲染 p32 原图看了：**确实是左右双栏、横排繁体**。RapidOCR 默认按图像 y 坐标排序，会把左右栏逐行交错读——字全对、顺序全乱，这种稿子切条必错。

他们加了自动分栏（按行 x 中心聚类，双栏先左后右），修复后 bigram 从 40% 级升到 86.9%。**这个发现值钱**，任务书里没有，是我没预料到的。

### 2.2 s2t 后 40.5% → 85%，诊断准确

RapidOCR PP-OCRv4 中文模型输出简体，参考语料是繁体，精确匹配必然崩。加 OpenCC s2t 后回到 85%。判断正确。

**但 s2t 引入的错是确定性的，这点他们低估了**（见 §4）。

## 3 我实测出的错字：约 1–2%，方剂行更差

### 3.1 系统性的专项错形（6 页合计 5996 字）

| 正确形 | 实测 | 判定 |
|---|---|---|
| 㕮咀 | **收咀×1、哎咀×1，正确 0 次** | 100% 错 |
| 去滓 | **去澤×2、去溶×1，正确 0 次** | 100% 错 |
| 五苓散 | 江苓散×1，正确 3 | 25% 错 |
| 麻黃 | 麻奠×1，正确 7 | 12% 错 |
| 桂枝 | 佳枝×1、桂校×1，正确 18 | 10% 错 |
| 太陽 | 太階×1、太阿×1，正确 30 | 6% 错 |
| 翕翕 | 氯翁×1 | 错 |
| 入 | 直人、陷人、匯人、絲絲人扣、人於 —— **5 处「入」错成「人」** | |

### 3.2 s2t 的一对多错误（这是根子上的问题）

| 字 | 实测 | 应作 |
|---|---|---|
| `雲` | 9 次中 **7 次应为「云」**：「陳平伯雲」「《內經》雲」「之上雲者」「本論雲」「至雲惟小柴胡」 | 云（言说义） |
| `餘` | 「餘特補之」 | 余（自称） |
| `幹` | 「氣逆而內幹」 | 干（干犯） |
| `發` | 「非細心如發者」 | 髮 |

**这四类都是 100% 稳定复现的，不是随机噪声。** 靠「抽验 10%」抽不到就漏过去了——必须用规则全库扫。

### 3.3 「曰」错成「日」6 处

`【補日】`、`【正日】`、`故日氣之標`、`名日命門`、`餘日`、`日：`。

「曰」是注文里最高频的字，错一个就断句。全书必须全库扫。

## 4 结构性残留：6 页 2 处

| 页 | 残留 | 性质 |
|---|---|---|
| p29 第18行 | `傷寒論淺注補正卷三299` | **书眉漏删** |
| p32 第75行 | `①且：此下原衍一"而"字，據善成堂刻本刪。` | **现代整理者脚注**混进正文 |

**书眉为什么漏**：双栏页的书眉只印在右栏上方，不在页首。原规则按「页面首行」删，所以没兜住。p29 被误报成「图表页」，其实只是被这道书眉撑短了（505 字）。

**脚注为什么必须剔**：整理者校记是 20 世纪编辑者的话，不是唐容川的话。按契约 L2 只记注本说了什么。但这条校记对 L1 校勘有用，**建议单存 `整理者校记.md`，别丢**。

## 5 一个必须纠正的认知：bigram 85% ≠ 干净

p32 的 bigram 是 **86.9%**，比干净文本基线 85.8% 还高。但同一页人工核出约 25 处错字。

**原因**：bigram 是对 128 万字语料算命中率，常见字组合淹没了错误。这个指标能拦灾难（63% 那份），拦不住 1–2% 级的错误。

**我设 75% 门槛时的标定是「63% 坏 / 85.8% 干净」，中间没有第三档。** 现在知道 86.9% 也可以是脏的——**这门槛的判别力比我以为的弱**。

处置：不推翻门槛（它确实拦住了批次1 那份），但**全书交付不能只拿 bigram 当凭据**，必须交修正规则命中数 + 人工核过的页数。

## 6 处置：放行全书，四条硬要求已写进任务书

已写入两个包的 `任务书 §5.5`：

1. **s2t 四类歧义字（雲/餘/幹/發）用规则全库扫**，逐条记命中数。不许靠抽验。
2. **「曰」错成「日」全库扫**，改动进人工清单。
3. **标记词括号兜底**：`【補日］`/`【正日］` 现状说明规则只在左括号被替换时触发，全书必须保证成对。
4. **书眉 + 整理者脚注**：书眉按「行内出现 `傷寒論淺注補正卷X+页码`」删，不管在第几行；脚注移进 `交付/整理者校记.md`。

并要求全书 manifest 写明：**本注本文本为 OCR 产物，错字率约 1–2%，定位是「对照阅读级」，不作校勘底本。**

## 7 还差什么：样张没有切条

### 对条验收标准（公开给承包人，让他能自查）

1. `n` 与源文位置的秩相关 **≥ 0.95**
2. 逆序 ≤ 5 处、最大降幅 ≤ 10 页
3. 抽读 15 条，注文与骨架原文对应无误

**第 1 条不过＝错挂，退回重挂；第 2 条不过但 1、3 过＝个别异位，可放行。**
