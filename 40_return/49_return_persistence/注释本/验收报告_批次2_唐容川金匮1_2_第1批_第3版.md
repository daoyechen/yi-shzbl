## 三、节切分：作废

交 44 行。**29 行的「节首句」不是句首，是句中截断**：

```
节3  義尤顯然。仲景言痰飲之人…      ← 前半句在上一行
节5  備。言臟而不及腑…              ← 以「備。」开头
节20 胸，進一層立論。雲胸滿者…      ← 从「胸」字中间切
节40 防己黃芪桂枝各三兩茯苓六兩      ← 这是方剂组成行
节44 桂甘姜棗麻辛附子湯方            ← 这是方名
```

只有 15 行是真正的句首。p2–p7 六页仍然一个节界都没有——第2版退回时点的就是这个，第3版没改。

节切分不是体力活，是体例判断：节 = 陈修园一段串讲，节末必是「此言…也 / 此爲…而出其方治也 / 此承上節…」这类小结句。让承接方猜只会在「切太粗」和「切太碎」之间摇摆（第2版 16 节、第3版 44 行碎句）。

**决定：节切分收归验收方，在合稿前统一做。批2/批3 只交转录 + 方剂表。**
