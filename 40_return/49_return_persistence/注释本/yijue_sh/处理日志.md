## 三、卡在哪

1. **本书是「串解」不是「逐条注」**。陈修园按症候、按法、按节次串讲，不逐条出注，且大量条文只以方名带过（「宜桂枝汤」「宜四逆辈」），一条注文往往对应一组条文。挂条只能取「该段主要针对的那一条」，不是原书自述的条号——原书根本没有条号，只有「节」。
2. **长段跨条，切分点由我判断**。原书一段常跨数十条，我按内容切成多段（例：太阳篇末「推而言之」切 8 段、阳明篇「何谓能食不能食」切 8 段、少阴篇「曷言标本」切 6 段、厥阴篇「三章一节曰」一段切 11 段）。**这些切分点是整理者所加，非原书分段**；原书该处是整段连读。
3. **原书「第×节」有误标**。阳明篇「何以谓正虚」段两处标「第十八节」，前者内容为「身如虫行皮中」（实为 196），后者为「面合赤色不可攻」（实为 206）。按内容分别归 196、206，未按误标归同一条。
4. **篇序与条号序不一致**。少阳篇、阳明篇内多处回引太阳篇条文（96、97、99、101、103、106、148、172、173、177、318、354、389 等），阳明篇「何谓名同而实异」又回引 237、257、259–262。交付按 `n` 单调排，这些注文因此排到了其所属条号的位置，与它们在原书中的篇次不同。**未按原书篇序排**，此处按任务书「按骨架 n 排」处理。
5. **太阴篇「从阳化」一段无对应条**。「何谓太阴之邪从阳化。伤寒论云。发汗后不解。腹痛。急下之。宜大承气汤」——L1 273–280 无「太阴急下」条，暂归 279（太阴转属、腹满痛之条），依据是下文紧接「腹满时痛属太阴……桂枝加芍药汤」，同段同证。
