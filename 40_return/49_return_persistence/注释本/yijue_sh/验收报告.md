## 三、收的理由

1. **节次换算可验**：少阴篇「第×节」= 280+×，交付方逐节核过原文首句；厥阴篇按章累计。这类换算最易出错，实测对得上。
2. **误标处理正确**：阳明篇两处都标「第十八节」，它按内容分别归 196（身如虫行皮中）与 206（面合赤色不可攻），没跟着错标走。
3. **挂不上只 2 条**（两篇序），理由正当；篇首总论按 `【总论】` 挂提纲条，33 段，体例统一。
4. **原书错字逐处列条号**：KT KT（31、182）、缺字（62、82、96、180、185、230、346、374）、「策七节」→「第七节」（279、280 一带）。可用于以后升校勘级。
