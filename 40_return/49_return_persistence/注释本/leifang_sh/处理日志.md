## 2. 没做什么

- 未对原书影印本：全程仅用随包电子文本，未核对任何纸本或影印，
  不能保证个别字与原刻本一致。
- 未做校勘：错字、缺字、异体字照原样保留，未改正、未补字。
- 未改骨架：条号一律取自骨架文件，未自建编号、未重排、未合并或拆分骨架条。
- 未收目录与著录：<目录>、书名/作者/朝代/年份等著录行不作为注文，
  另列于挂不上清单。
- 未做简繁／异体转换：注文原字原标点照录；仅在锚定匹配环节对经文做
  归一化（浓→厚、症→证、KTKT→几几等），不改写入 text。
- 未对注本做「方歌」独立切分：徐氏方下议论（如别症变症篇的按语）属
  方后总论，已归入该节首锚条并标【总论】。

## 3. 卡在哪

- 本书结构决定覆盖上限：徐大椿只引需要加注的条文，398 条中 225 条有
  >=10 字连续原文，另有 173 条即使以碎片（7-9 字）计亦仅零星出现。
  本次锚定取 >=10 字连续原文，宁缺勿滥，故实得 192 条。若后续放宽碎片
  匹配，可再增若干条，但错挂风险上升。
- 原书顺序与骨架不一致：本书按方编次（桂枝汤类→麻黄汤类→柴胡汤类→
  承气汤类……），同一方之下回引别篇条文，条号天然乱序。挂条一律改按
  骨架 n 排序，原书此处顺序不同，日志此处说明。
- 单调化丢弃 22 条：这些条在节内锚点上与主导条构成倒序（跨篇回引），
  按任务书要求未强行挂入。清单见挂不上清单。
- 方药组成段归属：本节只论一方，方药组成属该方本身而非对某条经文的注，
  已归本节首锚条并标【方】。

## 4. 不确定的

- 依据中等的条目：节首【方】段归本节首锚条，但「本节首锚条」由锚定结果
  决定，若该方下首条未被引录，方药段会挂到次条。涉及各节首条，需人工确认。
- 段长偏长的条目（如 n=108 别症变症按语 2078 字、n=97 小柴胡按语 654 字、
  n=394 妇人杂病按语 442 字）：这些是方后总论而非逐句注，段长天然偏大，
  验收抽条时应看注文是否与该条经文相关。
- 电子文本残字：原电子文本有占位字符（如「项背强KTKT」）、残字、
  缺字，照录未补，涉及条号以骨架原文含「几几」者为准。
- 未逐字对原书影印，文字残错率未实测；「对照阅读级」为目标档位，非实测结论。
