## 2. 没做什么

- 未对原书影印本：全程仅用随包电子文本，未核对任何纸本或影印，不能保证个别字与原刻本一致。
- 未做校勘：错字、缺字、异体字照原样保留，未改正、未补字。原书 OCR 残缺如「项背强KTKT」（KT 为占位）照录，共 16 处，未猜补。
- 未改骨架：条号一律取自骨架文件，未自建编号、未重排、未合并或拆分骨架条。
- 未收目录与著录：<目录>、书名／作者／朝代／年份等著录行不作为注文，另列于挂不上清单。
- 未做简繁／异体转换：注文原字原标点照录；仅在「锚定匹配」环节对经文做归一化（病患→病人、荣→营等），不改写入 text。

## 3. 卡在哪

- 类编特性导致一段【目】常同时注释【纲】内多条经文，按任务书「一条多段多条记录」处理为同一注文挂到多个 n；验收抽条时应按「这段注文是否论及该条经文」判断，而非要求注文只讲一条。
- 原书顺序与骨架不一致：本书按症状类编（如「发热」「恶寒」篇），挂条一律改按骨架 n 排序，原书篇序已打散，日志此处说明。
- 部分【纲】引文为《伤寒论》辨脉法、痉湿暍、死候、附录内容（如「问曰脉有阴阳」「太阳病发汗太多因致痉」），不在 398 条骨架内，无法挂条，入挂不上清单，未硬塞。
- 少数条因异文差异未挂上（如骨架条176「里有寒]／注本「里有邪」、条11「病人身太热②」），宁缺勿滥，未强行匹配。
- 一条经文的注文分散在多篇，切分点由「【纲】引文命中」自动判定，属整理者判定，非原书分段。

## 4. 不确定的

- 依据中等的条目：条1「太阳之为病脉浮头项强痛而恶寒」（首段注文出自「六经主症」篇，偏六经辨治总论）；条13、条35（注文横跨「表症」「发热」多篇综合论述，非专条专注）。这些条号依据经文锚成立，但注文覆盖范围偏宽。
- 电子文本残字：16 处「项背强KTKT」中的 KT 为原电子文本占位，照录未补，涉及条号以骨架原文含「几几」者为准。
- 未逐字对原书影印，文字残错率未实测；「对照阅读级」为目标档位，非本次实测结论。
