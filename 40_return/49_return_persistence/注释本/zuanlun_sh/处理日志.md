## 一、做了什么

### 1.1 步骤（可复现）

1. **解包与核对**：用 python `zipfile` 解 7 个文件，按 `manifest.json` 逐件核 sha256，一致；全文 313,978 字节／109,250 字符／77,395 汉字。
2. **去标签、并硬换行**：原文本按约 50 字硬折行，段界不可靠。做法是把 `<篇名>`/`<属性：>`/`<目录>` 行单独摘出，正文按"汉字流"重排（保留原始字符偏移映射），只以汉字序列做定位，不以换行断段。
3. **锚定经文引文**：以骨架每条 `原文`（去 `[方N]`、`用前第N方`、`一云…`、`〔方N〕`、①② 等标记后）为模板，在正文汉字流上做「10 字滑窗汉明 ≤2」＋「6-gram 命中」两种候选，候选再按 `difflib` 局部比对覆盖率打分取优，全表按覆盖率排序去重（间距 <12 字视为同一引文）。命中 382 处（其中 12 处为人工指定，见 §4.3），余 370 处程序判定。
4. **切注文**：注文 = 该条引文结束处 → 下一条引文起始处。引文终点取「比对末块位置之后、最近一句句末标点」；跨 `<目录>`/`<篇名>` 一律截断（防篇首绪论、方剂附录混入）。同一条分多段者合并为 1 段（见 §1.3）。
5. **清洗**：删换行与空白、去 `属性：`、去行首错位的注音括注（`（KT同）`「（蛔同）」等，≤8 字）、去句末 ≤4 字无标点残尾、去首尾孤立标点。古籍原字、原标点、原错字一律不动。
6. **排序与自检**：按 `n` 升序输出（原书顺序与骨架不同，见 §3.2）；跑 `工具/自检_注本.py 交付/ --side sh`，硬伤 0。

原书段界被硬折行抹平，注文首尾只能靠比对推定。规则是"引文末块之后、最近一个句末标点"。已知副作用：

以上均属切分判断，非原书分段；如需更贴近原书面貌，建议以影印本核段。
