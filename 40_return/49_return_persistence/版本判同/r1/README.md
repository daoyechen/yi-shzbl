# 交付落这里

在核定台（`工具/*.html`）里点右上「**导出交付 JSON**」，把导出的文件直接放进本目录，**不要改名**：

```
H01_待核校核定_交付.json
```

## 导出文件长什么样

```json
{"key":"…","title":"…","exported":"2026-11-13T…","total":115,
 "done":110,"flagged":5,
 "rows":[{"id":"T0026-俞桥本四部丛刊","choice":"残","text":"","note":"只剩半句"}]}
```

- `choice` 为空 = 没做
- `choice` 为 `?` = 判不了（存疑）
- `note` 是你写的备注

## 交之前

1. 页面顶部「已定 / 存疑 / 共」三个数对一下，未做应为 0。
2. 跑一次结构自检：

```bash
python3 ../工具/自检_核定台.py ../工具/*_配置.json ./H01_待核校核定_交付.json
```

看到 `✓ 结构自检通过` 再发回。
