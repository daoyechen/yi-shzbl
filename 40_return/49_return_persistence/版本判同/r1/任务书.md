# M01 · 金匮异文对齐（机械包）

> **性质：机械。** 纯字符比对，不需要文献判断；判断不了的地方按规范留「待定」，不要猜。
> 预计：一个熟手 1–2 天；有现成 diff 库的话半天。

---

## 一、要交什么

| 文件 | 内容 |
|---|---|
| `交付/异文标注.json` | `{"版本名": {"条号": "标注后的整段文本"}}`，465 条 × 4 版 |
| `交付/04_差异索引.md` | 由你的脚本生成：有差异的条列表（条号、篇、各版差异片段）|
| `交付/跑批日志.txt` | 参数、耗时、失败条号（一条不漏地列）|

4 版是：`邓珍本1340`、`医统正脉1601`、`俞桥本四部丛刊`、`人卫排印本1964`。
赵开美本1599 **不参与**——它就是骨架本身。

---

## 二、输入

```
数据/01_条文总表.json     465 条，每条含 宋本(骨架原文) + 各版{状态,原文} + 置信
数据/骨架_金匮条级.json    骨架原始结构（只读，别改）
数据/各版原文/*.md         五版全文（要查上下文时用；不要拿它当对齐源，它是渲染件）
```

`01_条文总表.json` 里 `各版[版本]["状态"] == "无"` 的格子跳过（那些条本版没有，另行处理）。

---

## 三、标注规范（照这个来，别自创）

1. **基准**：`宋本` 字段（赵开美 1599 原文）。
2. **标法**：输出该版**本版原文**，把与骨架不同之处用 `【】` 括起。
   - 例：骨架「太陽病，發熱無汗，反惡寒者，名曰剛痙。」
     邓珍「太阳病，发热无汗，反恶寒者，名曰刚【痓】。」→ 只标异字。
3. **只标「字」的差异，不标标点、空格、换行。** 各版标点体系不同，标了全是噪音。
4. **繁简/异体不算异文。** 先用 `数据/繁简映射.json` 归一（该表 `人→患` 一条是错的，已剔除，别再加回来）；
   归一后仍不同的才标。异体字对（欬/咳、痓/痉、㣲/微、沬/沫、榖/谷…）按「不算」处理，但要**另记一份清单**
   `交付/异体字对照.json`，供以后统一。
5. **整段缺失/多出**：该版此条文字明显是相邻条串进来的（对照 `证据` 字段里的段号），标 `〔串条〕` 并把可疑部分括起，不要硬对齐。
6. **长度 1 字的差异也标**（一个字常常就是全部意义，如 汗/无汗）。
7. **不许改字**。输出文本必须能在原 `原文` 里逐字找回（除 `【】` 外零改动）。自检会查这条。

---

## 四、做法建议

```python
# 骨架/本版 都先做：去标点 → 繁简归一（用 繁简映射.json）
# 再做 difflib.SequenceMatcher(None, a, b, autojunk=False) 的 opcodes
# 对 'replace'/'insert' 段：在本版原文的对应位置插【 】（位置映射要按去标点前的索引回填）
```

难点只有一个：**去标点后的下标要映射回原文下标**。建议建 `[(归一字符, 原文下标)]` 列表再回填，
不要直接对原文做 diff（标点会把 opcode 切碎）。

---

## 五、自检

```bash
python3 工具/自检.py 交付/异文标注.json
```

会查：① 4 版 × 465 条的键齐全 ② `【】` 成对且不嵌套 ③ 去掉 `【】` 后能逐字还原本版原文
④ `〔串条〕` 只出现在证据含「缺」「串」的格子 ⑤ 打印差异条数与分布。

---

## 六、验收标准

- 自检全绿。
- 差异条数落在 300–465 之间（低于 300 说明归一过头，把真差异也吞了；高于 460 说明标点没去干净）。
- 随机抽 20 条，人工复核标注位置正确率 ≥ 90%。
- 交回的 `04_差异索引.md` 能被 `35_总装产出_金匮_v0.1.0/02_条文对照本.md` 对照上。
