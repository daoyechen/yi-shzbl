# 交付格式（M01）

## `异文标注.json`

```json
{
  "邓珍本1340": {
    "1": "问曰：上工治未病，何也？○师曰：夫治未病者，见肝之病，知肝传脾，当先实脾…",
    "2": "夫人禀五常，因风【气】而生长…"
  },
  "医统正脉1601": { … },
  "俞桥本四部丛刊": { … },
  "人卫排印本1964": { … }
}
```

- 键：条号（字符串或整数都认）
- 值：**本版原文**，差异处用 `【】` 括起
- 本版「状态=无」的条不必出现
- 去掉 `【】` 后必须与本版原文逐字相同（自检会查）

## `异体字对照.json`

```json
{"欬": "咳", "痓": "痉", "㣲": "微", "沬": "沫", "榖": "谷"}
```
只收你在归一过程中实际遇到、且判为「同字异写」的对。

## `04_差异索引.md`

按条列：条号 / 篇 / 各版差异片段（每版一行，≤120 字）。格式照 `35_总装产出_金匮_v0.1.0/04_差异索引.md`。

## `跑批日志.txt`

命令行、参数、耗时、失败条号（若失败必须逐条列出，不许只写「有少量失败」）。
