## 二、口径（与任务书第三节逐条对应）

1. **基准**：`01_条文总表.json` 的 `宋本` 字段（赵开美 1599）。赵开美本不参与标注。
2. **只标字**：标点、空格、换行全部先剥掉，diff 在「只剩汉字」的串上做；标点系统差异一条没标。
3. **归一三层**，归一后仍不同才算异文：
   - **PUA 回填**：医统电子本 15 个私用区码位按 H02 已判结果回填（`󿀌`=也、`󿀎`=見…），**只用于比对，不改原文**，否则 1436 处方框会全成「异文」。
   - **繁简**：以包内 `繁简映射.json` 为底，**剔 3 条错项**（见第五节），补 648 对。
   - **异体/俗写**：201 对（含数码大写 叁/弍/贰/伍/拾、形近代用 巳/已/己、俞桥以「楼」代「樓」等）。
4. **上下文规则 25 条**（只在特定词里换，避免误伤）：`右X味→上X味`、`方寸七→方寸匕`、`栝樓→栝蒌`、`芒消→芒硝`、`脾王→脾旺`、`小腹→少腹`、`知毋→知母`、`川芎→芎藭`、`旋复花→旋覆花`、`甘烂水→甘澜水`…
5. **脱字单列**：本版缺字在「只输出本版原文」的格式里**没法用【】表示**（`【】` 里什么都不放会被自检判「空括号」，放任何说明字符又会破坏「去【】＝原文」）。故一律不括，改记 `脱字清单.json` 与索引里的「脱 n 字」。
6. **串条**：同样无法在正文里写 `〔串条〕`（会破坏还原），故整段可疑的格照常括起，另记 `疑似串条.json`（86 格）并在索引里标「整段」。

## 四、自检

**来件 `工具/自检.py`**：

```
✗ 有差异的条 989，高于 460：标点/繁简没去干净
（共 1 处错误）
```

①②③（键齐 / 括号成对不嵌套 / 去【】逐字还原）**全过，0 错**。只有 ④ 报数。

**④ 的口径有问题**，三条数摆在一起看很清楚：

| 口径 | 数 | 与 300–465 的关系 |
|---|---:|---|
| 4 版合计（自检 ④ 实际算法） | 989 | 超；但它把「一版有异文」的条重复计了 4 次，上限 1860 |
| **按条去重**（一版有即计 1） | **394** | **落在区间内** |
| 逐版 | 240 / 232 / 276 / 241 | 均低于 300，说明没有「归一过头、把真差异吞了」 |

也就是说：**按条去重 394 条，正好落在 300–465**；自检把「（4 版合计）」当成了条数。要让 ④ 字面通过，只有两条路——吞掉真差异，或每条只留一版标注。前者违背「不臆造」，后者等于丢 3/4 的活。两者都没做，来件脚本也一个字没改，留总装裁定。

**`工具/自检_补充.py`（新增，可复核）**：把 ①②③ 原样再查一遍，④ 改成按条去重，另加两条来件没有的硬查——`【】` 里不许只有标点（专门抓「标点没去干净」）、脱字/串条清单条号必须落在 1–465。结果：

```
按条去重：394 条；逐版：邓珍 240、医统 232、俞桥 276、人卫 241；4 版合计：989
错误：0
✓ ①键齐 ②括号 ③还原 ④按条去重 ⑤括号无标点 ⑥清单条号 —— 全过
```

## 五、数据侧发现（提请总装注意）

1. **`繁简映射.json` 有 3 条错项，不止任务书点出的那一条**：
   - `人→患`：任务书已说错，剔。
   - `內→纳`：应为 `內→内`。留着会把「为內所因」中的「內」单方面变成「纳」，人卫作「内」，凭空造出 50 处假异文。
   - `疸→胆`：疸自成本字（黄疸）。留着会把 17 条黄疸条全标成异文。
   三条均已剔除，剔除位置在 `工具/norm_tables.py` 的 `TRAD_BAD`，注释写明原因。
2. **医统 PUA 必须先回填再比对**。不回填，医统 457 格里几乎每格都有方框，异文数会翻倍且全是假阳性。本次按 H02 的 15 码位映射做**比对时替换**，原文一字未动。
3. **骨架收文偏窄**：205 处「整段」标记中，多数是**方后服法/附方未入骨架**（如条 26 宋本止于「大棗十二枚」，邓珍连服法一整段）。这类不是版本差异，是骨架条界问题，索引里已标「整段」，建议总装复核条界后再刷新高亮。
4. **邓珍 31 格低覆盖（0.00–0.05）** 集中在 p119/123/153/222/255/346/348/399/475/520/534/584/594/664/799/800/810/817/878/956/1008/1044/1048/1051/1052/1246/1255/1291/1509/1530/1531——与 H01 判定的「整格取到邻条文字（错行）」完全对得上，非本次对齐之误。
5. **人卫 45 格低覆盖** 是条界不同（人卫另立条、把两条并作一条），按人卫条号并回即可，见 H01 核对记录第 3 条。
6. **「病有血分水分」条**（条 233）三版均判「无」，本次未给文本，与 H01 结论一致。
