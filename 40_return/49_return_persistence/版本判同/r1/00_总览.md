# 36 · 剩余工序派发包

> 2026-11-13 拆包。**六个包，三种性质**，包名前缀就是性质：
>
> | 前缀 | 性质 | 怎么干 | 交什么 |
> |---|---|---|---|
> | `M` | **机械**（纯脚本，不需要判断）| 写代码跑，跑完自检 | 脚本 + 产出 JSON |
> | `L` | **LLM**（可批量判断，但要看文义）| 模型逐条过，人抽检 | 逐条结论 JSON |
> | `H` | **人工**（必须看原件/上下文）| 浏览器开核定台，点选 | 导出的 JSON |
>
> 人工包都配了 **单文件 HTML 核定台**（`工具/*.html`）：双击即开，不用装环境，
> 点选后自动存本机浏览器，干完点「导出交付 JSON」交回。

```
H02 ──(13 个字)──┐
                 ├─→ M01 异文对齐 ──→ 重出 04_差异索引 / 页面【】高亮
H01 ──(115 格)──┘        ↑
                         │

L01 邓珍重切条 ──→ 邓珍包 v3 ──┐
L02 俞桥补录   ──→ 俞桥包 v3 ──┴─→ 重跑总装（assemble --骨架 jingui）
```

- **H02 最划算**：15 个码位，做完医统全文 1436 个方框一次消掉，且直接影响 M01 的比对质量。
  包内配齐五版书证 + 原书/影印 + 双栏核定表，**答案不进包**，由接包人判定（详见该包任务书）。
- **M01 依赖 H01/H02**：字没认出来、格子没定性，异文会标错。
- **L01/L02 只影响各自版本**，与 M01 可并行。

## 三、所有包共用的硬规矩

1. **不臆造。** 判不了就写「判不了 / 存疑」，不许用推测填空。宁可交 80%，不留假 100%。
2. **不改骨架。** `骨架_金匮条级.json` 是坐标原点，一个字都不能动。改了就全库作废。
3. **编号空间不可混。** SH（宋本伤寒论 398 条）与 JG（赵开美金匮 465 条）是两套坐标，别互相套号。
4. **交回来要能直接跑。** 产出必须是 JSON，字段照《交付格式》写，别交 Excel 截图或聊天记录。
5. **每条结论带依据。** 一句话即可（页号、原文片段、判据），方便复核。

## 四、包内统一结构

```
<包名>/
├── 任务书.md        ← 先看这份
├── 数据/            ← 本次要用的全部数据（含全书原文，不必再找）
├── 工具/            ← 脚本或 HTML 核定台
└── 交付/            ← 空目录，交付物放这里 + 交付格式说明
```

各包实际大小与逐件 sha256 见 `_包清单.json`（H02 143 MB / H01 3.8 MB / M02 3.6 MB /
M01 3.5 MB / L01 2.2 MB / L02 1.8 MB）。

> **H02 为什么这么大**：按「带上对应的书本」的要求，包内自带四部丛刊影印
> 两册 PDF（约 125 MB）+ 10 张页图 + 五版全书原文。PDF 原交付著录为**俞桥本**，
> 但医统全文提要自称「四部丛刊景印明古今医统正脉本」，两者有出入；
> 该包 `数据/卷首题署对校.md` 与 `数据/书影索引.md` 已如实记录差异，不替派包方裁定。
> 判定用的材料都在包里，答案不在包里。

## 五、分发包（直接发这几个 zip）

六个包各有一个同名 `.zip`，**自包含**：解压后得到 `<包名>/` 目录，
双击 `工具/*.html` 就能干活，不必回本项目取数据。zip 用 UTF-8 文件名打包，
不含 macOS 的 `.DS_Store` / `__MACOSX` 垃圾。

| zip | 发给谁 | 解压后先做什么 |
|---|---|---|
| `M01_异文对齐_机械.zip` | 写脚本的人 | 读 `任务书.md`，跑脚本，自检 |
| `M02_方剂抽取_机械.zip` | 写脚本的人 | 同上 |
| `L01_邓珍重切条_LLM.zip` | 模型／标注 | 按任务书逐条过，导出 JSON |
| `L02_俞桥补录_LLM.zip` | 模型／标注 | 同上 |
| `H01_待核校核定_人工.zip` | 人工 | 双击 `工具/核定台_H01.html`，点选导出 |
| `H02_医统缺字识别_人工.zip` | 人工 | 双击 `工具/缺字台_H02.html`；包内含影印原书两册（约 125 MB） |

- 每个 zip 根目录另附一份 `00_总览.md`（共用硬规矩），包内自带全书原文，**不要自己去网上找版本**。
- 逐件 sha256 见 `_包清单.json`；六个 zip 自身的大小与 sha256 见 `_分发包清单.json`。
- **H02 包内不含答案**：15 个码位由接包人按五版书证判定；引擎推定值留在派包方
  `00_公共地基/引擎/H02_参考/`，不随包分发，只在交回后用于比对验收。
- 交回物一律放进各包 `交付/`，文件名照任务书，别改。

## 六、接包人第一件事

1. 读 `任务书.md` 的「要交什么」和「验收」两节——验收线写死了，达不到会被退回。
2. 人工包**双击 `工具/*.html`** 就能干活，不用装 Python；要跑自检才需要 Python 3。
3. 数据都在 `数据/` 里，**不要自己去网上找版本**。找来的版本和这里的底本对不上，
   比不做更麻烦。
4. 交回前跑一次自检，`✓` 之后再发。
