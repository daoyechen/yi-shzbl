## 一句话结论

这份写本 **正文 64 叶（p008–p071），覆盖宋本第 1–389 条，缺 390–398**，
抄于天保四年（1833），行款 **半叶 12–14 行 × 行 11–15 字**。
**因此与康平本（一丁十六行、行十五字）行款不合，不能判为同一系统。**

## 三条要记住的教训

1. **自检只查首句是不够的。** 末条号错 31 处，全都没报出来。
   已补末句回溯进 `45_派发包_A_田边宪本条目比对/工具/自检.py`。

   行款的数法必须给样图，不能只用文字描述。
3. **写本一页可跨篇，此时「末条号」没有定义域。** p010 一页里就有 248 条与 15/21/22 条。
   这一栏的设计是错的，下次派包删掉。
