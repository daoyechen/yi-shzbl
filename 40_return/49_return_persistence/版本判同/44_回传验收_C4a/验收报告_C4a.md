## 二、我错在哪（要记住）

**把负片扫描的黑底白字页看成了「手写写本」。**

判据失误链条：
1. 只看了 900px 拼图（页太小，黑底白字像反白手写）；
2. 没有回到原始 PDF 抽页验证；
3. 「写本」这个判定没有做**负片反转**这一步排除。

**规则**：判「写本 vs 刻本」必须先排除负片/反转扫描——黑底白字的刻本影印极常见（拓片式、阴刻式）。
看版框界行是否**印刷规范**、笔画是否有**刀口**，比看字迹形态可靠得多。
