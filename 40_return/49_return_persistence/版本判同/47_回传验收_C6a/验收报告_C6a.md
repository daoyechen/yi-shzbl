## 二、实质判错一件：C6a-003

**承接人判**：《傷寒六書》（明 陶华），并称 p008 目录与 p009 正文「不同书、疑混装」。

**实际是**：《傷寒總病論》（宋 庞安时）。三条硬证据：

1. **版心明题「龐先生傷寒論序」**（p002 中缝），序文首句「龐安常自少時善醫方，為人治病，處其死生多驗」——这是庞安时传。
2. **序末署「豫章黃」**（p003）：黄庭坚，元符三年（1100）为庞安时《伤寒总病论》作序。史有其事。
3. **p008 目录正是《伤寒总病论》卷四、卷五的篇目**：伤寒劳复证、斑豆方论、天行温病论、辟温疫方论。
   而 p009 的百合病，也在该书卷四。**两页同属一书，不是混装。**

误判的来路：看到「伤寒劳复证」就归到陶华《伤寒六书》。但《伤寒六书》是陶华的六种著作（明理续论、家秘的本等），
**没有「斑豆方论」「天行温病论」「辟温疫方论」这些篇目**。

讽刺的是：原件文件名写的就是「S064宋版.伤寒总病论」，这次文件名是诚实的，承接人没信。

## 三、更要紧的问题：6 件里只有 1 件是《伤寒论》的版本

| 编号 | 是什么 | 是《伤寒论》的版本吗 |
|---|---|---|
| C6a-001 | 傷寒六書（明 陶华） | **不是**，明代伤寒学著作 |
| C6a-002 | 尚論篇（清 喻嘉言） | **不是**，清代伤寒学著作 |
| C6a-003 | 傷寒總病論（宋 庞安时） | **不是**，宋代伤寒学著作 |
| C6a-004 | 注解傷寒論（金 成无己注） | **是**，唯一一件 |
| C6a-005 | 傷寒百證歌（宋 许叔微） | **不是**，宋代伤寒学著作 |
| C6a-006 | 傷寒直格（金 刘完素） | **不是**，金代伤寒学著作 |

承接人六件全判「另一版 → 记为新 witness」，这是**术语没错、动作错了**。

「另一版」的意思是「与已收录 14 版不同源」——这没错。但任务书里这句「另一版 → 记为新 witness，独立一栏」，
会让人把这五件塞进 L1 版本栏。**那是错的**：L1 放的是《伤寒论》各版原文，这五件是另外的书。

**正确归属**：
- C6a-004 → L2 注本（成无己注系统，项目已有「注解伤寒论」栏，作同系统异本见证）
- C6a-001/002/003/005/006 → 参考书目（校勘参照），不进 L1 也不进 L2

**这是任务书第三次暴露同一个毛病**：四选一的判定值里没有「非本书版本」这一项。
前两次是 C4a-002（现代排印）、A 包的末条号，这次是「书都不是同一本」。
