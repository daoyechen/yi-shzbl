## 五、怎么做

### 5.1 OCR

横排简体、排印本、字口清楚，标准 OCR 够用。注意：

1. 按行取字，从左往右。
2. 双行小字（方剂组成、剂量）**单独成行**，别混进正文。
3. 异体字照录（`證`/`証`、`臟`），不改成正体；只改 OCR 形近误识，且逐条记。
4. 图版（若有）转文字描述，用 `〔图：…〕` 标注，别丢。

### 5.2 体例判读（最花时间的一步）

这是**陈修园《金匱浅注》+ 唐容川补正**的合编本，书里同时有多个人的话：

| 标记 | 归属 | `attr` |
|---|---|---|
| `【補曰】` | 唐容川本人语，**本包真正的目标** | `唐容川` |
| `【正曰】` | 唐容川订正陈修园处（同为唐氏语） | `唐容川` |
| `【蔚按】`/`【元犀按】` | 陈修园一系门人按语 | `陈修园` |
| `【程扶生】`等 | 所引前人注 | `引文` |
| 方名、组成、煎服法 | 方剂 | `方剂` |
| 无标记正文 | 《金匱》原文 + 陈修园《浅注》 | 原文不入 `text`；浅注标 `陈修园` |

**四类都进 `text`，只用 `attr` 区分。** 不要因为「只要唐容川」把别人删掉 —— 删了补不回来。

### 5.3 对条

陈修园**按「节」分，一节常含数条**，不是宋本/赵开美的条序。所以：

1. 拿 `【浅注】` 之前的原文句，与骨架（赵开美本 465 条）归一后匹配，定到具体条。
2. 一节覆盖多条时，注文归到该节**首条**的 `n`，被覆盖的后续条写进 `未覆盖条清单.md` 的「本包范围外 / 节下合并」。
3. **不许把同一段 `text` 复制到多条。**

### 5.4 覆盖与条数：**不设目标，按实测交**

> **2026-11-17 改。** 自检脚本里那个「条数下限」只是**防止交空包的健康底线，不是 KPI**。
> 不要为了过它去凑数 —— 把原文、别家注、自己写的话塞进 `text` 充条数，比少交几十条坏得多。

判好坏的标准只有一条：**每一条都对得上**。

交之前算两笔账：

1. **本包页范围内出现的条，每一条都要有归处** —— 要么进 `notes.json`，要么进 `未覆盖条清单.md`。不许留空、不许不写。
2. **`notes 条数 + 未覆盖条数`** 应当等于「本包范围内出现过的条数」。这个数不是 465/398（本包只是全书的一段），但你必须自己数出来写在日志里。

### 5.5 全书阶段四条硬要求（2026-11-17 样张验收后新增，取自伤寒侧实测）

姊妹书《伤寒论浅注补正》的样张（六页）已过 75% 门槛，但暴露的问题对本包同样成立。**这四条不过，全书退回。**

#### ⓪ 先花两小时试繁体模型（这一步在修正表之前做）

现在的链路是「RapidOCR 中文(简) → OpenCC s2t → 修正表」。**s2t 是最大误差来源**——`雲/云`、`餘/余`、`幹/干`、`發/髮` 的错全是它带来的。

**先试：换繁体识别模型，直接出繁体，取消 s2t 这一环。** 候选：PaddleOCR `chinese_cht_PP-OCRv3/v4` 的 rec 模型导出 ONNX，或 RapidOCR 加载自定义 `Rec.model_path`。

**验收口径**：同一批样张 3 页跑两遍对比——

1. bigram 有效率不低于现在的水平
2. **人工核这 3 页，`雲/餘/幹/發` 四类错必须降到 0**

两条都过 → 用繁体模型，① 的修正表作废（②③④ 照做）。不过 → 退回 s2t + 修正表。
**别在这条上耗超过半天。**

#### ① s2t 的一对多歧义字，必须用规则修，不许靠抽验

伤寒样张实测：`雲` 9 次里 **7 次应为「云」**（「某某雲」「《內經》雲」「之上雲者」）；`餘`→余、`幹`→干、`發`→髮 各 1 次。**四类都是 100% 稳定复现，抽验 10% 抽不到就等于没查。** 全书跑完用修正表过一遍，逐条记命中数。

#### ② 「曰」错成「日」，必须全库扫

伤寒样张 6 页查出 6 处（`【補日】`、`故日`、`名日`、`日：`）。「曰」是注文最高频的字，错一个就断句。全书必须扫 `補日`/`正日`/`故日`/`名日`/`日：`，改动进人工清单。

**这是算术闭合，不靠抽读、不靠段数对账。** 段数对账发现不了这个漏——第2批交的「76 段全入」是真的，但仍有 19% 的字没进 notes。

### 5.9 卷首页必须人工核阅读顺序

凡含「卷X」大标题 + 署名块（`漢張仲景原文`…`云航參校`）的页，**自动分栏会失效**：标题与署名块干扰 x 聚类，退化成按 y 排序，整页左右栏逐行交替。

- 正确顺序：**左栏整栏读完 → 右栏整栏**
- 署名块**整块删**，不保留、不入 text
- 全书这类页只有 3 页（伤寒 p21/p42/p72），逐页人工核


### 5.10 页首续文的 attr 不能机械继承（2026-11-18 新增，**必读**）

跨页续文（页首无标记段）**不许一律记 `陈修园`**，也**不许整段套用上一段的 attr**。

它接的是上一段，作者不一定同一个人；而且同一段里常常前几十字还是唐容川收句、后面就转回陈修园浅注。

**典型实例**（批1 n=1 seg6，已回原页核过）：

```
…此非太陽中風而｜名之曰傷寒。其名爲傷奈何？以膚表第一層而受損傷也。｜此論寒傷太陽之膚表。受業薛步雲：按寒陰邪也…
        ↑ 唐容川「正曰」在此收句                  ↑ 此处起转回陈修园浅注
```

这一段要切成两条：`名之曰傷寒…受損傷也。` 归 `唐容川`；`此論寒傷…` 起归 `陈修园`。

**判界线的三个标志**：

| 标志 | 归属 |
|---|---|
| `此論……` / `此一節言……` / `此二節……` / `此下總論……` / `此言……也` | **陈修园**浅注总述，从这里起转回他 |
| `受業××云/按`、`男××按`、`次男元犀按` | **陈修园**门系 |
| `西醫` / `油膜` / `連網` / `三焦` / `膜網` 等唐容川特有词 | 通常仍在 **唐容川**话里 |

**每段切完必须在 `处理日志` 记一行**：

```
条N segM 前 X 字归唐容川，余归陈修园，界在「此論寒傷太陽之膚表」
```

**判不了的就整段留 `陈修园` 并在 `体例核实` 记存疑**，不要猜。

### 5.11 篇题、卷题不入 notes

篇题（`辨太陽病脈證篇` 等）、卷题（`傷寒論淺注補正卷一下`）**不是注文**，不入 `notes`。

- L2 只放注文；篇名由 L1 骨架提供，重复放会让同一格出现两遍篇题
- 计入 `字符守恒` 的 `剔除·篇题` 项，逐条列页码

### 5.12 字符守恒的「剔除」必须分项

`剔除` 不许写成一个总数，要分项：

```markdown
| 项目 | 汉字 |
|---|---:|
| notes 正文 | 0 |
| 经文（随浅注保留于 notes，未单列） | 0 |
| 剔除·署名块 | 0 |
| 剔除·书眉 | 0 |
| 剔除·整理者脚注 | 0 |
| 剔除·页锚点 | 0 |
| 剔除·篇题 | 0 |
| 未归条但已说明 | 0 |
```

- 每项要能在转录全文里指认（页码或正则），页锚点可只报条数
- 剔除总量超过转录汉字 2% 要在表下单独说明原因

**经文口径已定：不剥离。** 串讲体经文与注文语法粘连（「太陽病，當惡寒發熱。今吐傷中氣……」），剥掉前半后半是断头句，强行切会误删。L1 那格已有原文，注文里重复一遍正好标明「这段在讲哪句」——郝万山、胡希恕两份讲稿同样如此。

### 5.13 段必须在句末断开，缝合不许跨条（2026-11-18 1_2 实战，**必读**）

伤寒 1_2 第1版有 **64 处句子被从中间切开**（235 只剩「愈，宜麻黃湯。」5 字、237 只剩「黑。宜抵當湯下之。」7 字）。
第2版用「跨页缝合 + 段尾补句末标点」修到 0，但缝合按「跑到句末」结束，**把下一条的经注一起焊进了上一条**，又出 4 处节界偏移：

| 条 | 焊进来的东西 |
|---:|---|
| 233 | 234 桂枝汤注 + 235 麻黄汤注 |
| 234 | 236 的经文串讲 |
| 215 | 216 的注 |
| 237 | 238 的注 |
| 395 | 396 的注 |

**四条硬规则：**

1. **段必须在句末标点处断开。** 段尾不是 `。！？；」』` 就是切错，同条多段也一样。
2. **跨页续文只接到「上一条的末句」为止。** 一旦出现下一条的经起句、或新的 `【述】`/`【蔚按】` 块，立即收住，另起一段/一条。
3. **不许给段尾硬补句号。** 补标点会把真断点盖住，验收时只能靠人读。
4. **交前跑断句自检：**

```bash
python3 工具/断句自检.py 交付/notes.json
```

`句中切断`、`一段多标记`、`可疑标记` 三项必须为 **0**；`碎段` 只提示，逐条说明为什么合法（如「此起下文諸節厥逆之意」这类短述）。

**判据一句话：这段话说的是哪一条的经文。** 说不清就是切错。

### 5.14 附篇、跋语、无骨架条：不入 notes（2026-11-18 新增）

凡在 JG 465 骨架中**没有对应条号**的整段文字（附篇、跋语、序、目录、校记），**不进 `notes.json`**。

做法：

1. 另交 `交付/附篇_无骨架条.md`，逐段：

```
<!-- 书页N / 类别（附篇|跋语|序|目录）/ attr -->
（该段原文）

```

2. `manifest.json` 记：

```json
"附篇": {"范围": "书页X–Y", "字数": 0, "原因": "JG 骨架无对应条号，不入 L2 条级数据"}
```

3. `字符守恒` 记入 `未归条但已说明`，仍须闭合。

理由：L2 的 `n` 只能是 JG 条号。把附篇挂在末条下，阅读页会在那一条显示上万字跋文。伤寒 1_2 的 n=398 曾挂 13,005 字（全书 14.9%），已拆。

## 六、边界

1. **底本是简体排印本，交付统一转繁体**（与同书伤寒卷、L2 其余注本一致）。转繁按 `数据/用字表.csv`，不许用转换器默认：`证→證`、`湿→溼`、`里（内义）→裏`、`云（说义）→云`、`余（自称）→余`。交前跑 `工具/用字检查.py`，残留必须 **0**。
2. **不许改字**（除 OCR 形近误识，须逐条记录）。
3. **不许判断对错。** L2 只记录注本说了什么。
4. **不许补条、不许补页。**
5. **不许猜 `attr`。** 判不出写 `引文` 并在 `体例核实.md` 记「存疑」。
6. **不许动骨架**（只读）。
7. **不许越出本包页范围。** 相邻页的内容留给对应包，别抢。
8. **不许为凑数掺水。** 别把原文、别家注、自己写的话塞进 `text` 充条数。
9. **本包每一条都要有归处**（notes 或未覆盖清单），不许静默留空。
10. **不许三批合交。** 见 §5.6，合交只验第一批。
