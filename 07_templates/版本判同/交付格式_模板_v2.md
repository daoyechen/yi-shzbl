# 交付格式

交一个文件：`判同.json`（UTF-8，UTF-8-SIG 亦可）。模板见 `模板.json`。

## 顶层

```json
{
  "包": "C6a 版本判同",
  "交付人": "你的名字或代称",
  "日期": "2026-11-XX",
  "items": [ ...5 条... ]
}
```

## 每条

| 字段 | 必填 | 取值 | 说明 |
|---|---|---|---|
| `编号` | ✅ | `C6a-001` … `C6a-006` | 照抄，不要重编 |
| `判定` | ✅ | `同版` / `同系统异本` / `另一版` / `非本书版本` / `无法判定` | **五选一**，不许自创 |
| `归属` | ✅ | `L1版本栏` / `L2注本` / `参考书目` | 与判定配套：非本书版本→参考书目；注本→L2注本 |
| `题名` | ✅ | 文本 | 以卷首/书名为准，照录不校 |
| `卷数` | ✅ | 文本 | 不知道写 `"未得"` |
| `撰注` | ✅ | 文本 | 撰人／注家／校者，照录 |
| `刊刻` | ✅ | 文本 | 年·刊者·刻坊；现代书则写出版社+年 |
| `载体` | ✅ | `影印(丛书)` / `原件翻拍` / `现代排印` / `写本` / `钞本` / `稿本` / `活字本` | 七选一 |
| `藏馆` | ✅ | 文本 | 有馆藏印/水印就写，没有写 `"未得"` |
| `行款` | ✅ | `半叶N行×行N字` | 数不出来写 `"测不出"` 并说明原因。**行款是本批最硬的判据，务必数** |
| `依据` | ✅ | 数组，≥2 项 | 每项 `{"页":"pNNN","观察到":"..."}` |
| `未决` | ✅ | 文本 | 判不了要补什么，写清页号；无则 `"无"` |

## 依据怎么写

- `页` 必须是 `pNNN`，且该页在 `数据/判读页/<编号>/` 里真实存在。
- `观察到` 只写**图上看到的**，不写推测。
- 好例子：`"p004 版权页：湖南科学技术出版社 2014.12，ISBN 978-7-5357-…"`
- 好例子：`"p002 半叶十行，行十九字，版心题『注解傷寒論 卷一』"`
- 差例子：`"看起来像宋版"`（无页号、无观察）
- 差例子：`"文件名说是赵开美刻"`（用文件名当证据，直接退回）

## 三条不许

1. 不许留空字段。没有就写 `"未得"`。
2. 不许自创判定值（如「疑似同版」「基本一致」）。也不许把「非本书版本」写成「另一版」——那是两回事。
3. 不许在 `依据` 里引用文件名。
