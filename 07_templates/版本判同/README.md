# 版本判同 · 派包模板 v2

> 由 C6a 那包的任务书改来。改的原因：**四选一的判定值连续三个包栽在同一个坑。**
> 下一包直接复制这三个文件，改编号与件数就能用。

## 一、v2 改了三处

### 1. 判定从四选一改成五选一

补一项 **`非本书版本`**。

旧模板的「另一版 → 记为新 witness，独立一栏」是错的。C6a 那批 6 件里有 5 件
（伤寒六书、尚论篇、伤寒总病论、百证歌、伤寒直格）**根本不是《伤寒论》的版本**，
承接人全判「另一版」，照旧模板就该塞进 L1 版本栏——那是把五本别的书当《伤寒论》录进对照表。

新模板在判定前先问一句：**它跟宋本 398 条能不能对上？** 对不上，多半压根不是这本书。

### 2. 每条加 `归属` 字段

`L1版本栏` / `L2注本` / `参考书目`，且与判定配套。
自检会拦「判非本书版本却归 L1 版本栏」这种矛盾。

### 3. 行款给了数法，不再只说「数一下」

A 包承接人报「半叶 8 行」，实测 12–14 行——他把「半叶」和「一丁」（一叶两面）搞混，
据此判「与康平本行款相合」，结论全废。

新模板写死三步：只看一个半叶、挑满行的一列数、写死数字不写「约」。
