# 交付格式

## 只交这几样

```
交付/
├── notes.json
├── manifest.json
├── 处理日志.md
├── 挂不上清单.md
├── 自检输出.txt
└── PACK_VERSION.md
```

任务书、数据、工具都不用打回来。

**回传命名**：派发包名去掉 `.zip` 再加 `_RETURN.zip`（去掉 `_RETURN` 即还原派发包名）。
修订版在包名加 `_r2`／`_r3`，不得同名覆盖。

> 本项目的 `处理日志.md` 对应通用模板里的 `receipt`，`挂不上清单.md` 对应 `gaps`。
> 名字用中文，字段要求相同——不要因为换了名字就省内容。

## notes.json

```json
[
  {"n": 1, "versions": ["宋本"], "text": "注文正文…"},
  {"n": 1, "versions": ["宋本"], "text": "同条第二段…"},
  {"n": null, "scope": "pian", "pian": "辨太阳病脉证并治上第五  合一十六法  方一十四首",
   "title": "太阳总论·发汗利水", "versions": ["宋本"], "text": "【总论】…"}
]
```

| 字段 | 类型 | 规则 |
|---|---|---|
| `n` | 整数／null | L1 骨架条号。**本书不建第二套编号**；`scope` 非 `tiao` 时写 `null` |
| `scope` | 字符串 | 可省（默认 `tiao`）；`pian` 篇级总论／`book` 全书读法、序例 |
| `pian` | 字符串 | `scope=pian` 时必填，用 L1 篇名原样；`book` 写 `null` |
| `title` | 字符串 | `scope` 非 `tiao` 时必填，6–20 字 |
| `versions` | 数组 | 全书一致，填任务书指定值 |
| `text` | 字符串 | 纯文字。无 `<>`、无 `属性：`、无硬换行、无占位词 |

- 同一条注分几段就写几条记录，`n` 相同，按原顺序。
- 条注（`scope=tiao`）的条号必须单调不减。跳号可以（注本不全注），倒序不行；笔记（`book`/`pian`）另排，不参与条号单调。
- `text` 里可以保留原书的 `【总论】` `【方】` 这类前缀标记。

## manifest.json

```json
{
  "id": "注本ID",
  "name": "书名（注者）",
  "targets": ["宋本"],
  "base": "作者、书名、成书年、电子文本出自哪一版",
  "source": "原件/电子文本位置（文件名、字节数、C5 编号、分级）",
  "source_page": "书页区间；没有纸页定位时写“电子文本，无页码”",
  "layer": "L2",
  "status": "录入中",
  "条数": 0,
  "条注数": 0,
  "笔记数": 0,
  "覆盖": "0/398",
  "text_source": "OCR（引擎+版本）或电子文本（文件名+台账编号）",
  "proof_level": "对照阅读级（残错 ≤2%，未逐字对原书影印）",
  "files": {
    "原样": "转录_原样.md（只读）",
    "校订": "转录_校订.md（可迭代）",
    "校正表": "校正表.csv（页/原文/改文/依据）"
  }
}
```

`base`／`source_page`／`text_source`／`proof_level`／`files` 必填。纸页无法定位时明确写「电子文本，无页码」或「原件未得」，不许编造页码；来源不明写「不明（原电子文本无底本声明）」但不许留空。

> **`files` 两种口径，按任务类型选，不许混：**
>
> | 任务 | `files` 写什么 |
> |---|---|
> | **注本结构化（本任务）** | **交付物清单**（数组）：`["notes.json","manifest.json","处理日志.md","自检输出.txt","挂不上清单.md"]` |
> | 转录／校勘 | **层级件**（对象）：`{"原样":…,"校订":…,"校正表":…}`，见 `50_data/51_notes/契约.md` |
>
> 承接注本任务时用数组，别照抄对象写法。

## 处理日志.md

必须写四件事：

1. **做了什么**——扫了哪些页／篇，挂了多少条。
2. **没做什么**——哪些段没核、哪些只粗分、有没有对原书影印。
3. **卡在哪**——挂不上的注、原书顺序与骨架不一致的地方。
4. **不确定的**——错字疑点、条号判断依据薄弱的条目。

**「逐字过，未见需改」这类话会被直接退回。**

## 自检输出.txt

```bash
python3 工具/自检_注本.py 交付/ --side sh    # 或 --side jg
```

把终端输出原样存进这个文件。不许手抄、不许改数。

## 挂不上清单.md

只列**成段却挂不上任何条**的文字：

| 编号 | 原书位置 | 原文首 40 字 | 字数 | 为什么挂不上 |
|---|---|---|---|---|

标签行、著录行（书名／作者／朝代／年份）、`<目录>` 不算正文，另设一节列出即可。

## PACK_VERSION.md

包内已给模板，填三处：

```markdown
- 派发包：01_02_伤寒医诀串解_yijue_sh_派发包.zip
- 派发包 SHA256：<填你算出的值>
- 收到日期：YYYY-MM-DD
```

算哈希：`shasum -a 256 01_02_伤寒医诀串解_yijue_sh_派发包.zip`
与我方在包外给的 `.sha256` 比对，一致说明传输没坏。
