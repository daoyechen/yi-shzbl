> 这是全项目的**目录总表**，也是基础层的说明。改结构先改这里。
> 迁移完成后，本文档是唯一权威；根目录不再放 `40_目标架构_*.md` 这类临时文件。

## 一、这一层是干什么的

`00~09` 是**基础层**：工具、规则、骨架、模板。它们跨书通用，换一本古籍可以整套搬走。

**这一层的东西全入库**，因为删了不可再生（骨架、规范、11 版基线）或不可替代（引擎、模板）。

## 三、编号规则

**顶层就是 0~99，每项一个号，不嵌套。** `00~09` 是基础层，`10` 起按流水阶段走。

| 号段 | 用途 | 例 |
|---|---|---|
| `00~09` | 基础层，**每个号一类，平级** | `08_tools` 直接是顶层，不在 `00_base` 里 |
| `x1` | 入口：收件、临时、未整理 | `11_inbox`、`21_`、`31_`、`41_return_tmp` |
| `x2~x8` | 并列：按任务或类型，有几档建几档 | `32`~`36`、`51`~`53` |
| `x9` | 出口：持久、成品、定稿 | `19_nas`、`49_return_persistence` |

**不预留空号。** 不为了"整齐"摆空目录；`50_data` 没有出口概念，就不设 59。

**数据的「写」有唯一归属，「读」是跨阶段的。** 骨架（`01_skeleton`）、版本档案（`15_catalog`）、注本（`51_notes`）会被 `20_process`／`30_dispatch` 反复读取，但只写在一个地方。放哪看「写在哪」，不看「谁读」。
**顶层用英文名，任务子目录用中文。** 英文名跨平台、脚本安全；任务名是中文概念，保留可读性。

## 四、入库边界

| 层 | 入库 | 机制 |
|---|---|---|
| `00~09` `50_data` `90_out` | **是** | 正常跟踪 |
| `10_material` `20_process` `30_dispatch` `40_return/41_tmp` `.archive` | **否** | `.gitignore` 整层忽略，只放行 `README.md` |
| `10_material/15_catalog` | **是** | 例外：物料层的账本，结论不可再生 |
| `40_return/49_persistence` | **是** | 显式放行 |

**不需要 `.keep`。** 每个目录都有 `README.md`，它进了 git，目录就不会消失。`.keep` 是没 README 时的替代品，这里不用。

`.gitignore` 写法：

```gitignore
# 流水层：只跟踪 README.md
10_material/*
!10_material/README.md
!10_material/11_inbox/
10_material/11_inbox/*
!10_material/11_inbox/README.md

20_process/*
!20_process/README.md
!20_process/*/
20_process/*/*
!20_process/*/README.md

30_dispatch/*
!30_dispatch/README.md
!30_dispatch/*/
30_dispatch/*/*
!30_dispatch/*/README.md

40_return/41_return_tmp/*
!40_return/41_return_tmp/README.md
.archive/*
!/.archive/README.md
```
