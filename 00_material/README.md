> 物料是「原料」，不是「项目数据」。项目数据在 `data/`、`41_注释本对比/`、`00_公共地基/`。

## 两个入口

| 入口 | 是什么 | 规则 |
|---|---|---|
| `inbox/` | 新找到的、还没整理的 | 谁都能扔。**定期清**：要么整理进 NAS，要么删 |
| `nas/` | 已入库到 NAS 的 | 软链到 `/Volumes/189XXXX8728/学习/02医/伤寒杂病论`。**入了这里的不许随便删，除非用户授权** |

```bash
# nas 软链的实体路径（换机器/换 IP 要重建）
ln -sfn "/Volumes/<卷名>/学习/02医/伤寒杂病论" 00_material/nas
```

NAS 目录里分两层：

- `n/` —— 已初分的，按 `02_高价值版本`／`03_同名异刻`／`05_注本辑校`／`07_电子文本` 这类编号归类
- `old/` —— 可能相关但没分类，或者根本与本书无关
