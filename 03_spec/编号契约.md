# 编号契约 · 公共地基

> **硬约束:编号与字段不得自创。** 本文件是全部版本包的唯一编号依据。
> 与参考任务包 `rtq-busi-diwu` 的同名硬约束一致。

---

## 一、条号:唯一坐标系

| 项 | 规定 |
|---|---|
| 基准 | 宋本《伤寒论》398 条(李顺保《伤寒论版本大全》所补加的现代条文序号) |
| 写法 | **逐位汉字**:99 = 九九,391 = 三九八,10 = 十,11 = 十一,20 = 二十 |
| 范围 | 1–398,**零缺号**(由 `skeleton.load_skeleton()` 断言) |
| 唯一性 | 骨架中条号不得重复;发现重复即骨架错误,提更正建议 |
| 修改 | **任何版本包不得修改骨架。** 只能提「更正建议」到本包 `争议与疑难清单.md`,由总装裁决后统一改版并重发骨架 |

**为什么锁死**:条号一旦漂移,已交付各包的主表、对照本、浏览器全部对不上,返工成本随版本数线性增长。

## 二、版本单元 ID

| 场景 | ID 格式 | 例 |
|---|---|---|
| 该版某条对上宋本某条 | `{版本名}#{序号}` | `唐本#37` |
| 该版独立内容(宋本无对应) | `{版本名}-独-{四位序号}` | `唐本-独-0123` |
| 校记锚点引用的宋本条号 | 直接用宋本条号整数 | `32` |

- 序号从 1 起,独立内容从 `0001` 起,四位补零。
- 独立内容**不入主表**,单独进 `本版独有.md` / `05_版本独有内容.md`。
- 版本名一经登记不得改;若必须改,由总装统一重发并重跑相关包。

## 三、字段名契约

各版本包的 `版本包.json` 与总装主表使用**同一套字段名**,总装方不做字段翻译。

### 条级(`条目[]`)

| 字段 | 类型 | 含义 |
|---|---|---|
| `条号` | int | 宋本条号 1–398 |
| `篇` | str | 宋本篇目原文 |
| `页` | int | 宋本该条所在 PDF 页 |
| `宋本` | str | 宋本该条正文(骨架原文) |
| `状态` | `"有"` / `"无"` | 该版是否有对应 |
| `置信` | str | `校记锚点`/`高置信`/`中置信`/`低置信` |
| `原文` | str | 该版原文 |
| `异文` | str | 差异以【】标出 |
| `分段` | list | 多段对应时逐段给出 `{置信,页,原文,异文,score}` |
| `原因` | str | 状态=无 时必填,取值见下表 |
| `证据` | str | 状态=无 时必填,**该版原文**依据 |

### 「此版无」原因枚举(六类,不得自创)

| 原因 | 判据 | 证据要求 |
|---|---|---|
| `选集未收` | 该本收录范围自某篇起,前此诸篇不收 | 起始卷次原文 + `收录范围.start` |
| `本版仅残卷` | 该版正文自称残卷 | 篇名/标题含「残卷」 |
| `原书残损` | 该版自陈虫蛀残缺 | 凡例/校记原文 |
| `体例不同` | 该版以他种体例编排,条不构成对应单元 | 该版篇目原文 |
| `此版无此篇` | 该版篇目中确无此篇 | 该版篇目清单 |
| `暂未匹配` | 全文检索未见对应文字 | 待人工复核,**必须进待复核清单** |

**顺序不可乱**:按上表自上而下问,先命中先判。

### 独有级(`独有[]`)

| 字段 | 含义 |
|---|---|
| `iid` | 独立内容 ID |
| `页` | 所在 PDF 页 |
| `文本` | 原文 |
| `前置` | 是否属前置材料(序/凡例/目录/校注说明) |

## 四、页码约定

| 记法 | 含义 |
|---|---|
| `p123` | 原书 PDF 页码 |
| `<!-- p123 -->` | 转录件中的页锚标记 |

- 页码 = **PDF 物理页**,不是原书印刷页。二者相差 10(印刷页 + 10 = PDF 页)。

(各版「考」在该区间之后。)

## 五、文件名与目录约定

```
<版本包目录>/
  spec.json              唯一配置文件
  版本正文/*.md          转录件,带 <!-- pN --> 页锚
  交付/                  交付件
    版本对照.md
    本版独有.md
    锚点表.md
    待复核.md
    体例说明.md
    方剂表.md
    版本包.json
    清单.md              DoD 逐项自检
    原始资料索引.md
    争议与疑难清单.md
    SKILL.md
  _工作/                 中间产物
    单元.json
    篇目.json
```

- 版本包目录名:`版本包_<版本名>/`,如 `版本包_桂林古本/`。
- 转录件文件名:`版本正文/<两位序号>_<版本名>.md`,序号沿用本轮已用号段(09 起接续,不重排)。
- 中间产物一律 `_` 前缀。
- 包内不出现总装级文件(主表、对照浏览器),那些由总装统一生成。

## 六、禁止事项

1. 禁止自创条号体系、禁止自创原因类别、禁止自创字段名。
2. 禁止修改 `00_公共地基/骨架/宋本398条.json`。
3. 禁止在包内放无原文依据的结论 —— 无依据就写「暂未匹配」并进待复核。
4. 禁止把「体例不同」当「缺条」用 —— 两者结论强度不同。
5. 禁止在未核实的情况下断言某版为伪托或某版为善本 —— 那是版本学考据,不在本流程范围;若涉及,写进争议清单请总装裁决。
