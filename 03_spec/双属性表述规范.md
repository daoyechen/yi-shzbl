# 双属性表述规范 · 公共地基

> 源自参考任务包 `rtq-busi-diwu` 的核心方法论:
> **「同源 ≠ 无用」** —— 不许拿"同源"一句话把一个底本的校勘价值抹掉。
> 本规范把它推广到《伤寒论》多版本对照场景。

---

## 一、为什么需要

一个版本与宋本的关系,**从来不是单一维度**。用单一指标(如覆盖率)去概括,必然要么高估要么低估。

**反面例子**:康治本对宋本的覆盖率只有 27/398(6.8%)。如果只按覆盖率说话,结论是"康治本与宋本关系疏远,价值有限"。但康治本恰恰是现有资料中**唯一提供编者核定条号硬锚点**的版本(53 条「同《宋本伤寒论》第X条」校记)—— 没有它,另外 6 版的条号对应就只能靠算法猜。

**再一个例子**:唐本与宋本字面差异大(按方分篇 vs 按经分篇),覆盖率 242/398。但唐本作为孙思邈所见的**唐人传本**,其价值恰恰在于"它没有的东西"与"它多出来的篇目"。

---

## 二、两个必填属性

每个版本包交付时,必须同时给出:

### 属性 1 · 版本属性(这一版与宋本是什么关系)

| 取值 | 判据 | 含义 |
|---|---|---|
| `同源` | 与宋本(或与已登记的其他本)文字高度重合 | 文字谱系上同出一源 |
| `近亲` | 部分重合但有独立成分 | 共享部分祖本,另有自身增删 |
| `独立见证` | 文字差异显著,但年代或谱系上有据可证为另一来源 | 不共享直接祖本 |
| `残本` | 篇幅残缺,仅存部分 | 载体残缺,内容价值另计 |
| `体例异构` | 内容同源但编排方式不同 | 条不一一对应,需篇级/条级双层对照 |

> 取值可组合(如「残本 + 独立见证」「体例异构 + 同源」)。

### 属性 2 · 校勘功能(这一版能干什么)

| 取值 | 含义 |
|---|---|
| `可校正文` | 有正字/异文可用于校正其他本 |
| `可校篇目` | 篇目增删可用于判断他本取舍 |
| `可校方剂` | 方名/组成/剂量有出入可用 |
| `可校条序` | 条文顺序有别,可用以判断编次 |
| `可校体例` | 编排方式本身即证据(如康平本三格层次) |
| `仅存文献` | 存世价值大于校勘价值(残卷、伪托本等) |
| `不可校` | 无独立校勘作用 |

## 三、填写模板(进 `交付/清单.md` 与 `交付/结构化知识库.md`)

```markdown
### 本版双属性

| 维度 | 判定 | 依据(原文摘录 / 覆盖率数据) |
|---|---|---|
| 版本属性 | 体例异构 + 独立见证 | 本版目录作「太阳病用桂枝汤法第一」等,按方分篇;与宋本逐条覆盖率 242/398(60.8%) |
| 校勘功能 | 可校篇目 + 可校方剂 | 本版独有篇目 17 篇(见《本版独有》),为宋本所无;方剂组成与宋本多有出入 |
| 说明 | 覆盖率低**不等于**价值低 | 本版为孙思邈所见唐人传本,篇目与宋本不同构,故条级对齐率受限,篇级差异才是其主要价值 |
```

---

## 四、禁止事项

1. ❌ 只报覆盖率数字、不给属性判定。
2. ❌ 用「同源」当作弃用理由 —— 同源本仍可能是独立见证(参考包实证:第5底本覆盖率 94–98% 判同源,但保留 180 处正字,校勘功能上仍是独立见证)。
3. ❌ 用「差异大」当作价值高的证明 —— 差异大可能只是体例不同或转录质量差。
4. ❌ 把版本属性断言成定论而不列依据 —— 覆盖率是**指标**,不是**同源证明**。写「基于覆盖率,非同源证明」。
