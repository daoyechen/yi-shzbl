# 反幻觉规范 · 公共地基

> **原则:有的就有,没有的不臆造。**
> 落到可执行的条款 —— 每一条都能被机器检查或人工抽查。

---

## 一、五条底线

| # | 底线 | 判定 |
|---|---|---|
| 1 | **不补字** | 转录中缺字/残损一律留 `□`,不据上下文推补 |
| 2 | **不改字** | 异体字、通假字、俗体字一仍其旧,不校订(校订须总装裁决) |
| 3 | **不臆断缺条原因** | 「此版无」必须带原文依据;无依据写「暂未匹配」并进待复核 |
| 4 | **不算法拍板** | 匹配分只作召回与排序,不作裁决;低置信一律进待复核 |
| 5 | **不无声略过** | 任何"处理过但没写进交付件"的事,必须写进「本组未做」表 |

## 二、逐条检查项(交付前自检)

### 2.1 转录层

- [ ] 缺字位置为 `□`,数量与影印原页一致
- [ ] 未擅自补全、删改、调整标点
- [ ] 页锚 `<!-- pN -->` 与实际 PDF 页一一对应,无跳页无重页
- [ ] 圈码(①②③)原样保留,未与序号混淆
- [ ] **抽查 ≥20 条**(优先六经篇首尾)与影印原页逐字比对

### 2.2 对齐层

- [ ] 骨架未修改,条号集合 == {1..398}
- [ ] 每条「有」都有页码,可回溯
- [ ] 每条「无」都有原因 ∈ 六类枚举 + 非空证据
- [ ] 证据是**该版原文**(或其原句),不是"据查该版为残本"这类转述
- [ ] 校记锚点逐条核过(至少抽查 10 条):锚点也可能因转录而错位
- [ ] 低置信条目 100% 进了待复核清单
- [ ] 独有序 ID 唯一、格式合规、不与主表条号混淆

### 2.3 结论层

- [ ] 覆盖率数字与实测一致(不是估计)
- [ ] 双属性判定有依据,不用单一覆盖率下结论
- [ ] 不含"应该/大概/可能含有"这类无据推测 —— 推测写进争议清单并标 `[归属不确定]`
- [ ] 存疑、冲突、未决项已进 `争议与疑难清单.md`,不埋在正文里

### 2.4 交付层

- [ ] `清单.md` 里的每个数字都能在 `_工作/` 中间产物里找到
- [ ] 「本组未做」表已填,含原因
- [ ] `verify.py` 全 ✅

## 三、常见反幻觉陷阱(本项目已踩过的)

| # | 陷阱 | 表现 | 防线 |
|---|---|---|---|
| 1 | **把「未找到」写成「不存在」** | 匹配失败即判"此版无此条" | 原因枚举强制区分 `暂未匹配` 与 `此版无此篇`;前者必进待复核 |
| 2 | **把体例差异写成内容缺失** | 唐本按方分篇 → 误判大量"缺条" | `体例不同` 独立成一类,需篇目原文作证 |
| 3 | **把选集取舍写成版本特征** | 注解本选集只收卷五~十 → 误判"成本本无辨脉法" | `选集未收` 独立成一类,证据写明"本选集" |
| 4 | **覆盖率当同源证明** | 覆盖率 96% 就断言"同源" | 覆盖率是指标不是证明,须双属性表述 |
| 5 | **算法高置信当人工核验** | 高置信 0.87 就直接进交付 | 仍须抽查影印原页;转录错会被算法忠实放大 |
| 6 | **骨架自身的 OCR 残损未标记** | 条 154 编号为 `--五四` | 已记入 `修复记录`;发现新的须提更正建议 |
| 7 | **"此版无"只给结论不给依据** | 写"该版无此条" | 机器检查:证据不得为空 |
| 8 | **重文号/异体字被当噪声抹掉** | 敦煌本校注层 8 处残卷记号被排印成拉丁字母形(原始转录作 `n`) | 转录层规范:一字不改;发现异常列专项核校。**已核校**:6 处叠字重文号 → `々`;2 处单字省写 → 保留原印形 + 括注,不可写成 `々`(见 `记号规范.md`) |
| 9 | **把"标目为单字"的省写符号误判为重文号** | 标目「弱」「血虚」是单字,残卷记号代表的是那个字本身,不是"重复" | 写 `々` 会变成"重复前一字",与事实相反。判据见 `记号规范.md` §二 —— 必须同时满足「标目为叠字」+「记号紧跟其后」 |

## 四、存疑标记体系

| 标记 | 含义 | 用在哪 |
|---|---|---|
| `[归属不确定]` | 事实存疑,本包无法裁决 | 争议与疑难清单、待复核 |
| `[需原图核校]` | 需回影印原页确认 | 待复核、争议清单 |
| `[体例存疑]` | 归属该版还是他版,存疑 | 争议清单 |
| `[转录存疑]` | 转录本身可能有误 | 待复核 |
| `[已本组裁决,此处备案]` | 本组已定,仅备案 | 争议清单(供总装推翻) |

**禁止**用 `[?]`、`TODO`、`待定` 之类含糊标记 —— 一律用上表五类之一,让人一眼知道该找谁裁。

## 五、争议与疑难清单的三档分类

每条存疑项必须归入三档之一,并写明「需谁裁决」:

| 档 | 含义 | 裁决人 | 例子 |
|---|---|---|---|
| **A · 可自动定性** | 引擎可判定,只需跑规则 | 本组自行 | 「暂未匹配」中经全文检索确证无对应的 → 改判「此版无此篇」 |
| **B · 需人工裁决** | 需读影印原页或比较义理才能定 | 承接人 + 总装 | 锚点圈码错位;两处读法谁正 |
| **C · 方法论疑难** | 涉及判据/口径本身 | 总装(必要时外部专家) | 「此版无」某原因是否应改判;繁简差异是否计入异文 |

末尾附「未决事项汇总」表:`# | 事项 | 档 | 需谁裁决`。
