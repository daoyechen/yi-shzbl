# 前端约定（index.html）

> 从 `AGENTS.md` 搬出。改 `shjkit/htmlbuild.py` 前读这一份。
> 全部改动都在 `@media(max-width:820px)` 内，**桌面版不受影响**。

## 一、移动版布局

**顶栏（fixed，不随内容滚走）**：`☰` · 区切换 · `⌕`。搜索框默认收起，点 `⌕` 展开。

**导航条（仅「条文对照」视图，sticky）**
- 第一行：`N / 465 条` + 篇名 + `↑ ↓ ⚙`。分母取 `D.expect`（伤寒 398 / 金匮 465 固定）。
- 篇名用 `flex:1 1 0` 纯 CSS 自适应：没余量压到 0 宽（不占位、不换行），有余量才撑开。
  **这里不能放 `.sp` 弹簧**，否则余量被它吃光，篇名永远 0 宽。
- 第二行：点 `⚙` 才展开——只看有异文／全同／版本／状态／视图，压在**一行内横向滚动**。
  与桌面筛选行双向同步（`syncFilters()`），不允许两套状态。

**tab 行与统计条在移动版隐藏**，入口移进抽屉：`#dnav`（6 个 tab + 版本统计）、`#v-stat`。

**内容区独立滚动**：`.wrap` 为 `flex-direction:column; height:calc(100dvh - 52px)`，`main` 单独 `overflow-y:auto`。

**悬浮按钮**：右下角 `#fab`，单列 ⇄ 双列。用 SVG 图标，别用 `▥` 这类字符（字体缺字会变红线）。

## 二、四种视图模式

| 模式 | 实现 | 适用 |
|---|---|---|
| 单列 | 卡片纵排 | 通读 |
| 双列 / 三列 | **JS 按高度贪心分列**（`.mflow`+`.mcol`+`flowCards()`） | 一屏多看几版 |
| 左固定右滑 | `.pinsplit`：左 44% 底本不滚，右列独立 `overflow-y:auto` | 逐版横向对照 |

- 瀑布流**不用** CSS `column-count`：它是「先填满左列再填右列」，阅读顺序变纵向；
  版本对照要「同一行左右可比」，所以按 `offsetHeight` 逐个插入当前最矮列。
- **列高不齐是正常特征**，不要为了对齐留白。
- 左固定右滑的高度由 `fitPin()` 实算（`main.clientHeight - 导航条 - #detail 纵向 padding`）。
  只靠 CSS `height:100%` 不行：`#detail` 无确定高度时不撑开，右栏卡片会被裁掉。

## 三、完整性提示

`.integrity` 是 `position:fixed` 浮层，正常 3 秒淡出（不占布局）；**自检未通过 / 数据加载失败时常驻**。

自检会比对 `indep` 项数与 `stats[v].ind`。加了独有序内容必须同步 `stats.独有`，
否则页面报「独有序 1 ≠ stats 独有 0」。

## 四、踩过的坑（改之前先看）

1. **CSS 优先级**：桌面默认隐藏规则写在 `@media(max-width:820px)` **之后**，同优先级会覆盖移动端显示规则。
   用 `:where(.hd) :where(.srchbtn){display:none}` 把优先级降到 0 才修好。
2. **旧规则残留**：旧的 `.wrap{display:block}` / `main{overflow:visible}` 留在同一断点靠后位置，
   会覆盖新的 flex 布局。改布局必须**删旧规则**，不能只加新规则。
3. **字段口径**：`fang[版本][方名]={pg,zc}`，不是 `fang[方名][版本]`。写反了方剂页空白。
4. **数据要洗到能直接显示**：抽取结果常带网页残留（`File:…jpg`、`</div`）。
   清洗器不能整句匹配——M01 注入异文会把残留包进【】，变成 `File:【新编金匮方论`，
   要**只锚 `File:`** 再循环剥尾部。

## 五、部署与验收

**改了 `index.html` 或 `data/` 后，用户端报「数据加载失败：Failed to fetch」不等于代码坏了。**
这是缓存错配：HTML 与 `data/zones.json` 是强耦合的一对，浏览器缓存了旧的一半。

1. 先让用户强制刷新（`Cmd+Shift+R` / `Ctrl+F5`）或清站点数据；
2. 自己验证也要绕缓存：URL 加 `?v=时间戳`，或独立 `--user-data-dir` 起无头浏览器；
3. **`index.html` 与 `data/` 必须同一次提交推**，不可分批。

**移动端验收**：无头 Chrome 的 `--window-size` 在 macOS 上**不生效**（视口恒 500/756），
必须用「390px 宽的 iframe 包装页」测媒体查询。判断是否溢出看
`document.documentElement.scrollWidth === innerWidth`。

截图存档走 `截图存档/<日期>_<主题>/`，附一份 README 说明每张验什么。


## 六、图版显示

注文里带图的，存储与渲染约定见 `41_注释本对比/04_图版方案.md`。要点：

- 内嵌靠图注编号（正文「（图57）」→ `cap=="图57"`），不靠位置
- 无编号的图走注本级「图版集」，不进正文
- `loading="lazy"` 必加；移动版默认折叠成一行，点开才加载

## 七、注文卡（仅 `zhushi/` 站）

数据字段 `D.zhub`（注本表）+ `D.zhu`（`条号 → [{b,t,pg?,seg?,attr?}]`），来自 `41_注释本对比/`。
`gujia/` 站没有这两个字段，注文卡、筛选框、统计项**全部不渲染**——不靠开关，靠字段有无。

- **卡在原文各版卡之后**，同一 `select()` 里按 `zhu[n]` 顺序出，顺序即 `zhub` 顺序（时代序）。
- **长文折叠**：`max-height:calc(1.9em*6)` —— 必须取**整行**，取 `10.5em` 会切在半行上（试过）。
  渐变遮罩 `.ztxt::after` 只是提示「还有」，真正的展开入口是 `.zmore` 按钮。
- **点文字不折叠**，只有按钮折叠。文字要能选中复制。
- **`【…】` 不套 `<mark>`**：注文里的【解析】【按】是注本自身的小标题，不是异文标记，
  用 `ztxt()` 转成 `<b class="zhh">`。原文那条走的是 `mk()`，两者不能混。
- **搜索**：`ZHUHAY[条号]` 在 `loadZone` 时预拼一次；不许在 `makeMatch` 里现拼——398 条 × 1 MB 串会卡输入。

**注文条号越界 = 编译期硬失败**，不是页面告警。挂错条的注比少几部注本坏得多。
