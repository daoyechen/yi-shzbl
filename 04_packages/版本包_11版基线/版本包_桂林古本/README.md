## 五、五个缺口（已写进交付件，不掩饰）

1. **无影印件。** 1982 木刻板重印、1960 首版、2014/2024 中国中医药本均未到手，全部证据停在 **C 级**（今人整理本转述）。
2. **「黄蘖／桃核」是否被 1980 整理本现代化，未核。** 两源同作「黄柏／桃仁」，整理本内部比不出来。
3. **异文 925 处不能裁决孰是。** 整理本 ↔ 整理本只能显示分歧。
4. **与宋本 113 方无法逐味比组成。** 包内无宋本方书组成原文（骨架只到方名）。
5. **书目著录未实查。** 逐种标「未核」，列了应查的 8 种，不冒充查过。
