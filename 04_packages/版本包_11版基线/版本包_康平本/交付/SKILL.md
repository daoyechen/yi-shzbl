# SKILL · 康平本 判读经验

> 本文件记**本版专属**的判读口径，供后续同类工作复用。不讲通用流程（通用流程见 `公共地基/SKILL.md`）。

---

## 一、本版是什么样的书

- **底本**：日本康平三年（1140）内里司典药局抄本，影印见《伤寒论版本大全》第 59–134 页
- **版式**：左右分栏：左栏辨脉法、平脉法、伤寒例；右栏伤寒论。条文大字，注文小字，另有 ㊟ 记号
- **属性**：现存最接近「原本形态」的抄本，未经宋人重编
- **校勘功能**：校宋本之「合并/拆分」与「语序」；保存宋本删落的注文

## 二、本版特有的坑（判条前必读）

1. 「大阳」「大阴」为「太」之省，全本通例，不作异文
2. 「回逆」即「四逆」，「玄武汤」避宋讳改「真武」，均属本版用字
3. 114/115 两条论「结胸」与「藏结」的次序被钞胥互倒
4. 注文以「㊟」标记，与正文分行；判条时不并入正文

## 三、方法：句级窗口 + 三指标

1. **行级窗口不够。** 三版都存在「一行含多条」：康平本 一行内可并两三条。按行取窗，第二、三条必然被并进第一条。**必须先按 `。！？` 切句**（`；` 不切），再在句序列上取 1–8 句的连续窗口。
2. **窗口不能只取短窗口。** 短窗口能把 F1 刷满：曾出现「桂枝二越婢一汤」6 字窗口 F1=1.00。故窗口下限取 1 句、上限 8 句，按 F1 取 top6 去重，再由人裁定。
3. **三个指标一起看**：
   - `覆盖 = 命中字 / 宋本该条字数` —— 宋本这条有多少字见于本版；
   - `占比 = 命中字 / 本版窗口字数` —— 防「并进旁条」（窗口很长、只沾一点不算）；
   - `F1 = 几何平均` —— 两者都达标才算候选。
4. **置信由差异性质定，不由分数单定。** 差异全属 `{异体,通假,语序,省略,增字,衍字,同文}` → 高；含「异文」→ 中；分数太低 → 低。
5. **绝对命中字数门槛要按条长收敛。** 短条（如「少阳病欲解时，从寅至辰上」14 字）永远够不到 12 字门槛，门槛取 `min(12, L)` / `min(9, 0.7L)` / `min(7, 0.55L)`。
6. **一条正文只能被认领一次。** 同一 `(页, 文本[:24])` 被多条认领时，只留覆盖最高者，余者判「无」并在证据里写明「已判为宋本 N 条」。
7. **中低置信复核是「验既有对应」，不是重新海选。** 把引擎已配原文也放进候选，仅当它的 F1 高于新窗口时才优先——否则会把原本正确的对应判成「无」。

## 四、本版判条口径

- **大阳/大阴**：「大」为「太」之省,全本通例,一律按「太」读,记为异体,不改字
- **回逆**：即「四逆」,本版通例,记为通假/异体,不作异文
- **玄武汤**：避宋讳改「真武」,本版仍作「玄武」,记为异体
- **注文**：「㊟」所领为后人所加注,判条时不并入正文;若宋本相应位置有注文,记为体例归并
- **左右分栏**：左栏辨脉法、平脉法、伤寒例,右栏伤寒论;跨栏文字不得拼接成一条
- **语序**：本版多倒装(114/115),以「同字不同序」判语序,不判异文
