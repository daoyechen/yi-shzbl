# 高继冲本 对照 · 版本专属经验

> 本版是**方书体节录本**:一节一证一方,「症 → 脉 → 宜某汤」合璧。与宋本「六经条 + 方后语」是两种编排范式,
> 故对照必须做**语义级展开**,不能只做字面级。以下经验均来自 H 包实测(161 条对上的复核过程)。

## 核心判断

1. **本版实况**:对上 **161**/398(高 80 / 中 49 / 低 32);校记硬锚点 **0**;独有序 **399** 项;方剂 **65** 方(全为散剂)。
2. **双属性**:
   - 版本属性:**节录改编本(方书体)** —— 非白文本,是「同一批条文按治法重编」的宋代医方书形态。
   - 校勘功能:**可校体例 + 可校文字**(699 处异文),可反证宋本卷七–九「与六经重出」为后编。
   - **覆盖率 40.5% ≠ 价值低**:卷八本无霍乱、阴阳易、痉湿暍、百合、妇人诸篇,六经又是节录(太阳 178 条压成 37 节)。
3. **本版体例特点**:
   - **25 篇**(目录 p265 自称「凡二十五篇」)= 前置三篇(叙论/脉候/受病日数,对应宋本《伤寒例》《辨脉法》,**不在 398 骨架内**)
     + 六经「形证」六篇 + 可/不可发汗吐下灸火水温 **十三篇** + 汤散诸方一篇。
   - **可/不可十三篇不是宋本卷七–九的对位**,而是**宋本六经条文按治法重排**:宋本卷七–九所收条文与六经篇重出,
     本版把「按治法归类」升为**篇级**。所以「结胸,脉浮大,不可下」这类会出现在〈辨不可下形证〉,而它对的是宋本**太阳篇**第 132 条。
   - **一节一证一方**:治法以「宜某汤」缀于节末,与证同句;方皆「上件药,捣筛为散,每服四钱,以水一中盏」。
4. **本版记号与异体字**:圈码 ①–⑳ 嵌行末,页脚注以圈码起首;合并注写作「⑧、⑨圆:…」(p268 两处);
   缺字 1 处作 `□`(未补);「玄武汤」不避讳(宋本作「真武汤」);「荣卫不足」多处(宋本作「荣气不足」)。

## 操作步骤

### 一、判「有/无」的四步(本包主方法)

1. **先切节**:按篇题切出 336 节(前置三篇 60 + 六经 130 + 可/不可 97;汤散诸方按方计,不切节)。
   切节时**必须排除**:目录行(行尾带「…… 页码」)、页脚注行(`① xxx:`)、`……` 续行。
2. **只在本版侧找候选**:同一条文可能落在**六经篇**,也可能只落在**可/不可篇**;两边都要给候选。
3. **打分**:`0.32×字袋 + 0.22×覆盖宋 + 0.08×覆盖节 + 0.08×三字组 + 0.15×方名 + 0.15×症候`,
   再乘**六经归属一致性约束**(宋本属某经、候选节属另一经 → ×0.35)。阈值 0.46/0.36/0.30。
4. **人工复核覆盖**:阈值只作初判,逐条通读后写「定点裁定」(本包 52 条),把阈值误判拉回;
   **宁可退回「无」,不硬配**(本包退回 74 水逆五苓散、350 脉滑而厥白虎汤、379 呕而发热小柴胡汤、348 难治/不可治)。

### 二、展开四步法(本包核心,判「有」必做)

把本版「症+脉+宜某汤」展开成宋本式表述:

```
本版:太阳为病,头痛项强而恶寒,其脉浮数,宜桂枝汤。
 ① 去掉「宜某汤」尾注        → 太阳为病,头痛项强而恶寒,其脉浮数
 ② 句中「其脉」省作「脉」    → 太阳为病,头痛项强而恶寒,脉浮数
 ③ 补句号                    → 太阳为病,头痛项强而恶寒,脉浮数。
 ④ 缀「某汤主之。」          → 太阳为病,头痛项强而恶寒,脉浮数。桂枝汤主之。
宋本:太阳之为病,脉浮,头项强痛而恶寒。   ← 同证
```

**注意**:方名要**去掉「宜/可/与/当宜/宜服/可与」前缀**再比较,否则「宜桂枝汤」与「桂枝汤」对不上(本包曾因此少判 6 条);
「可与桂枝汤」的「与」也要去,否则会展开成「与桂枝汤主之」。

### 三、判「此版无」的三道闸

1. **是整篇未收,还是单证未收?** 先看目录 25 篇:无霍乱、无阴阳易 → 382–398 判「此版无此篇」。
2. **单证未收**:给「本版 N 节中无此证」+ **2–3 个全文检索 0 见的四字串**(从宋本条取 4-gram,取本版 0 见者),可复算。
3. **近似节为何不同**:指名候选节的页与原文 24 字,说明「证不同在哪」(如「本版只存泻心汤一节,无『先解表』的桂枝汤一节」)。

> 本版**不用**「选集未收 / 残卷 / 残损」三类:卷八 25 篇首尾俱全、38 页无残页,用这三类会把「体例不同」偷换成「没收」。

### 四、一节多证怎么办

本版一节可承载宋本 2–3 条(本包 7 处:桂枝汤中风 2/13、麻黄汤 46/47/55、小青龙 40/41、桃花汤 306/307/308 等)。
处理:**各条各判「有」,原节不重复计入独立内容**;在 `拆分留痕.md` 留痕,**不要改转录件分节**(强拆会破坏「症—脉—方」结构)。

### 五、圈码 ↔ 脚注

逐页取正文全部 ①–⑳,与页脚注**首字圈码集合**比对;合并注按「起首诸码」一次定义多码(如「⑧、⑨圆:…」定义 ⑧⑨ 两码)。
本包 38 页:**43 码 = 43 码,缺注 0 / 空注 0 / 重码 0**。

## 坑(都是本包踩过的)

| # | 坑 | 现象 | 解法 |
|---|---|---|---|
| 1 | 篇目标记不全 | 引擎篇目表只出 **24 篇**,《辨伤寒脉候》因篇题尾带 `④` 认不出 | `篇目标记` 补到 6 条;比对前先 `re.sub(r"[①-⑳]$","",t)` |
| 2 | 篇题用单 `#` | 《辨阳明病形证》全文唯一用 `#`,引擎只认 `##`,**整篇 40 节丢失** | 改 `#`→`##`(不改字);引擎侧建议加容错 |
| 3 | 目录行混入切节 | 「辨可温形证…………… 291」被当成篇题/条文 | 切节时排除含 `……` 的行 |
| 4 | 症候短词误触发 | 「小便不利」触发「利」,把「下利」条错配 | 长词优先,命中即 `replace(w,"　")` 消去 |
| 5 | 方名带前缀 | 「宜桂枝汤」≠「桂枝汤」,少判 6 条 | 比较前去掉 `宜/可/与/当宜/宜服/可与` |
| 6 | 跨经冒充 | 「太阴中风」被判成「少阴中风」(0.43 分) | 加六经归属约束 ×0.35 |
| 7 | overlay 不删键 | 判「无」的条目仍留着引擎的 `原文/置信/分段`,出现「状态=无 却带原文」 | 裁定里显式给 `原文=""`、`分段=[]`、`置信=None` |
| 8 | 引擎跑一遍就冲掉人工 | `pkgbuild` 覆盖 `版本包.json`,114 条掉回 82 条 | 人工裁定写 `交付/人工裁定.json`(引擎不碰),`overlay` 叠加 |
| 9 | 判定脚本不幂等 | 二次运行把上轮「有」当已定跳过,只剩 239 条 | 只读**固定清单**(`E已定.json`)与**原始基线**,不读自己的产出 |
| 10 | 展开式重复逗号 | 「下之不愈,,脉浮者」 | 先 `rstrip("，,。 ")` 再替换,最后 `re.sub(r"，+","，",s)` |
