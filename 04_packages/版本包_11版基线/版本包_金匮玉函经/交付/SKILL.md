# SKILL · 金匮玉函经 判读经验

> 本文件记**本版专属**的判读口径，供后续同类工作复用。不讲通用流程（通用流程见 `公共地基/SKILL.md`）。

---

## 一、本版是什么样的书

- **底本**：清康熙五十五年（1716）陈士杰刻本，影印见《伤寒论版本大全》第 147–254 页
- **版式**：八卷二十九篇，与《伤寒论》同源异形：太阳上中下合为「辨太阳病形证治第三/第四」，可/不可诸篇各自独立成篇
- **属性**：《金匮玉函要略方》一系，宋校三书之一，与宋本《伤寒论》同源同书之另一形态
- **校勘功能**：校宋本「分篇」与「并条」；保存宋本未收之可/不可诸篇与方后注

## 二、本版特有的坑（判条前必读）

1. 可/不可诸篇（发汗、吐、下、温、火、灸、刺、水）各立一篇，与六经条重出 144 项
2. 176 条本版作「白通汤主之」，自注「旧云白通汤；一云白虎者，恐非」——与宋本「白虎汤」明文异读
3. 231/232 两条在本版连抄为一长条，末作「但浮无余证者，与麻黄汤」
4. 辨太阴病篇仅 286 字，太阴条文多并入阳明篇末

## 三、方法：句级窗口 + 三指标

1. **行级窗口不够。** 三版都存在「一行含多条」：金匮玉函经 一行内可并两三条。按行取窗，第二、三条必然被并进第一条。**必须先按 `。！？` 切句**（`；` 不切），再在句序列上取 1–8 句的连续窗口。
2. **窗口不能只取短窗口。** 短窗口能把 F1 刷满：曾出现「桂枝二越婢一汤」6 字窗口 F1=1.00。故窗口下限取 1 句、上限 8 句，按 F1 取 top6 去重，再由人裁定。
3. **三个指标一起看**：
   - `覆盖 = 命中字 / 宋本该条字数` —— 宋本这条有多少字见于本版；
   - `占比 = 命中字 / 本版窗口字数` —— 防「并进旁条」（窗口很长、只沾一点不算）；
   - `F1 = 几何平均` —— 两者都达标才算候选。
4. **置信由差异性质定，不由分数单定。** 差异全属 `{异体,通假,语序,省略,增字,衍字,同文}` → 高；含「异文」→ 中；分数太低 → 低。
5. **绝对命中字数门槛要按条长收敛。** 短条（如「少阳病欲解时，从寅至辰上」14 字）永远够不到 12 字门槛，门槛取 `min(12, L)` / `min(9, 0.7L)` / `min(7, 0.55L)`。
6. **一条正文只能被认领一次。** 同一 `(页, 文本[:24])` 被多条认领时，只留覆盖最高者，余者判「无」并在证据里写明「已判为宋本 N 条」。
7. **中低置信复核是「验既有对应」，不是重新海选。** 把引擎已配原文也放进候选，仅当它的 F1 高于新窗口时才优先——否则会把原本正确的对应判成「无」。

## 四、本版判条口径

- **同源异形**：与《伤寒论》同源同书,分篇不同不等于内容有无;可/不可诸篇自六经析出,条文重出
- **形证治**：本版篇题作「辨太阳病形证治」,宋本作「脉证并治」,按同篇处理,记体例不同
- **白通汤/白虎汤**：176 条本版作「白通汤」并自注「一云白虎者,恐非」,是明文异读,判「有·中置信」
- **231/232 连抄**：本版把宋本 231、232 连抄为一长条,末作「但浮无余证者,与麻黄汤」,按两条分别认领
- **太阴篇**：本版辨太阴病仅 286 字,太阴条文多并入阳明篇末;归篇须按字符位置,不能按页界
- **可/不可篇**：各篇所载条文与六经条重出,判条时以六经条为主,重出项入《独有复核》不计独立
