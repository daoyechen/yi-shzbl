# 敦煌本 对照 · 版本专属经验

## 什么时候用它

- 「敦煌本这一版对上多少条?哪些条没有?为什么没有?」
- 「敦煌本的某条与宋本差在哪里?」
- 「敦煌本的校记锚点可信吗?」

**不适用**:版本真伪考订;义理校勘;临床应用。

## 入口判定

| 必需 | 说明 |
|---|---|
| 本版转录件 | `版本正文/` 下,带 `<!-- pN -->` 页锚 |
| 公共骨架 | `00_公共地基/骨架/宋本398条.json`(只读) |
| 引擎 | `00_公共地基/引擎/shjkit/` |

## 核心判断

1. **本版实况**:对上 1/398,高置信 0,校记硬锚点 0,独有序 73 项。
2. **双属性**:版本属性「残本(残卷)+ 独立见证」,校勘功能「可校正文(残存部分)」。**覆盖率低不等于价值低**。
3. **本版专属**:敦煌本**只存辨脉法 ×2 + 伤寒例残卷**,不含六经正文 —— 对上 398 条的覆盖天然极低是**版本实况**,不是缺陷。
转录中约 10 处重文号显示为 `n`(误识别),已列专项核校包(任务书 C)。

## 操作步骤

1. 打开 `交付/版本对照.md` 看逐条对照;`交付/体例说明.md` 看体例与原因依据。
2. 查某条:左侧「条号」→ 右侧各版。异文以【】标出。
3. 查缺条:`交付/体例说明.md` 的「此版无」原因分布 + 每条自带原文依据。
4. 需回影印原页:按条目的 `pN` 页码定位。

## 判断标准

- [ ] 「此版无」的每条都带原文依据
- [ ] 校记锚点与文字不符者已标 `锚点冲突`
- [ ] 独有序 ID 唯一,未混入主表
- [ ] 低置信条目已列入待复核
- [ ] `verify.py` 全 ✅

## 什么时候不该用它

- 判断该版真伪 → 版本学考据
- 改字定本 → 校勘定本,须总装裁决
- 临床方证 → 文本层结论不自动外推
