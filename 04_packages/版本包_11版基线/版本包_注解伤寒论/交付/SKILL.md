# 注解伤寒论 对照 · 版本专属经验

> 本版是**双层体例**：大字正文（＝宋本条文）＋ 小字成无己注。做对照不能只对正文，
> 注文要走独立通道——这是本版与其他 7 版最大的不同。

---

## 什么时候用它

- 「宋本第 N 条的成无己注是什么？在第几页第几卷？」
- 「本版对上多少条？哪些条没有？为什么没有？」
- 「某段文字是正文还是成注？分界在哪？」
- 「成无己引了哪些书？某人某条引了什么？」

**不适用**：版本真伪考订；义理校勘；改字定本；临床方证。

---

## 入口判定

| 必需 | 说明 |
|---|---|
| 本版转录件 | `版本正文/08_注解伤寒论_十卷全本.md`，79 个 `<!-- pN -->` 页锚 |
| 注文台账 | `_工作/注文单元.json`（855 项，每项带 `关联依据`） |
| 公共骨架 | `公共地基/骨架/宋本398条.json`（**只读，不许改**） |

| 影印 | `原料/影印原页/注解伤寒论/p0655–p0724.png`（**只覆盖卷五~卷十及卷四之末**） |
| 电子文本 | `原料/电子文本/注解伤寒论/` 10 卷（**卷二缺《伤寒例》**） |

**不接的情况**：要求逐条回影印核卷一~四（无影印）；要求改字定本；要求把注文塞进 398 条主表。

## 核心判断

1. **本版实况**：对上 **398/398**，高置信 **398**，校记硬锚点 **0**，独有序 **1102** 项，方剂 **148** 方；
   注文 **855 段**（挂条 467、独立 388、涉 372 条），引书 **18 种 360 处**。
2. **双属性**：
   - 版本属性：**同源 + 体例异构**（正文承宋本系统，另加注层、重排卷次、增「可不可」诸篇）
   - 校勘功能：**可校正文**（异文经赵本／医统本对校）＋ **可校体例**（注层为宋以后最早的全注本，可考注文与经文的界线）＋ **仅存文献**（成注本身即文献）
   - 覆盖率不是问题：398 条全对上，价值在注层而不在条文数量。
3. **本版体例特点**：
   - 一条大字正文 + 若干段小字注文交替；注文整段左缩约 2 字（影印 p0687 实证）。
   - 方名行／药行／煎服法行随前条，属正文侧；条文末有方序号 `[七]`／`[二十三]`。
   - 卷次与宋本不同：本版卷五起为阳明，宋本卷五起为阳明而篇次略异；本版另收辨脉法／平脉法／伤寒例／辨痓湿暍（宋本 398 条不含）。
   - 卷一~四据排印本转录（校记用行内括注），卷五~十据影印转录（校记用页脚圈码 ①–⑳）。
4. **本版记号与异体字**：重文号只用 `々`；缺字 `□`；异体字照录（痓／𥆧／龂／杏人／頞）；注文内 ①–⑳ 是「此处有校记」的指涉标记，不是注文内容。

## 操作步骤

1. **查某条的注**：打开 `交付/注文对照.md`，按 `## 宋本第 N 条` 定位；每条给【原文】【本版正文】【成无己注】【引书】【出处】【核对】。
2. **查某段注的归属依据**：打开 `_工作/注文单元.json`，看 `关联依据`（写「紧承正文块 #N（pX），该块与宋本第 M 条单调对齐（相似度 s）」）。
3. **查全部注文台账**：`交付/注文索引.md`（855 行，一条注文一行）。
4. **查引书**：`交付/成氏引书统计.md`（18 种 360 处，逐书列涉及条号）。
5. **回影印**：按条目 `pN` 定位 `原料/影印原页/注解伤寒论/pNNNN.png`；**版心页码 = PDF 页码 − 10**。
6. **判断某段是正还是注**：先看影印是否缩进 → 再看有无方序号 `[N]`（有则正文）→ 再看「也」密度与引书起头。
7. **改判后重跑**：`cd 裁定工具 && python splitmerge.py && python dedup.py && python attach.py && python patch.py && python attach.py && python t4.py && python render.py`。

## 什么时候不该用它

- 判断本版真伪 → 版本学考据，不在本流程范围
- 改字定本、出版底本 → 须总装统一裁决
- 临床方证 → 文本层结论不自动外推
- 想拿注文当「宋本条文」比对 → 注文不参与与宋本的字面比对，比对只对正文
- 要求「注文一律挂到某条」→ 388 段所承正文在宋本 398 条外，无条可挂
