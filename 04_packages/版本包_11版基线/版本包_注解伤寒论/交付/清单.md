# 清单（DoD 逐项自检）· 注解伤寒论注文对照

> 任务：**任务包 F · 注解伤寒论注文对照专项**
> 对象：《注解伤寒论》十卷全本（金·成无己撰，皇统四年 1144；明嘉靖汪济川校刊本／医统本系统）
> 交付形态：**一条宋本原文 + 一家成氏注解**的对照阅读件
> 版本包：`版本包_注解伤寒论注文对照/`
> **硬约束**：编号与字段不自创，全部沿用宋本 398 条条号与公共字段名；注文另编「注文序号」，不入主表。

## 一、一句话结论

成无己注文已从「本版独有」的黑箱里全部抽出，**855 段注文**逐段给出页码、篇次、卷次、引书与**关联依据**；其中 **467 段挂上宋本 398 条**（涉 **372 条**），得《注文对照.md》；剩余 **388 段**挂不上宋本条（多属辨脉法／平脉法／伤寒例／辨痓湿暍及卷七～卷十「可不可」诸篇——宋本 398 条本不含这些篇），按任务书要求**单列不硬塞**，在《注文索引.md》中标「独」并注明承哪个本版独有正文单元。宋本 398 条**全部对上**（398/398，高置信 398，暂未匹配 0，待复核 0）。

## 四、方法与复现

五步流水线（代码在派发包 `裁定工具/`，均以 `python <步骤>.py` 单跑，顺序固定）：

| 步 | 脚本 | 作用 | 产物 |
|---|---|---|---|
| 0 | `parse_blocks.py` | 逐行成块；`**…**` 正文标记拆分；页间断句续接；折行回并 | `_工作/块序列.json` |
| 1 | `classify.py` | 硬判（校记/释音/方名/药行/煎服法）＋ Viterbi（正/注）＋ 条号递进校正；方序号 `[N]` 作正文强标志 | `_工作/分层.json` |
| 2 | `splitmerge.py` | 「条文＋成注」挤一段者，按宋本条文字在段首的**前缀链**切分 | `_工作/分层_拆分.json` |
| 3 | `dedup.py` | 合并件两段互有重出者，保排印本段、影印段副本打 `skip` | `_工作/分层_去重.json` |
| 4 | `patch.py` → `attach.py` | 条级补挂（同篇、块首对齐、覆盖 ≥85%）＋ 篇级单调对齐（Needleman-Wunsch）＋ 注文随正文继承条号 | `_工作/注文单元.json`、`条级正文.json` |
| 5 | `render.py` | 渲染三件 | `交付/注文对照.md`、`注文索引.md`、`成氏引书统计.md` |
| 附 | `t4.py` | 8 条暂未匹配＋14 条中低置信复核，回写 `人工裁定.json` | `交付/人工裁定.json` |
| 附 | `check_etext.py` | 用包内电子文本逐段核对 | `_工作/电子文本核对.json` |

完整复现：

```bash
cd pkg_F/裁定工具
python classify.py && python splitmerge.py && python dedup.py \
  && python attach.py && python patch.py && python attach.py \
  && python t4.py && python render.py && python check_etext.py
cd ../派发包_F_注解伤寒论注文对照专项 && bash 自检.sh
```

`attach.py` 跑两遍是刻意的：第一遍产出空位清单，`patch.py` 据此补挂，第二遍落实补挂并重算对齐（`patch.py` 二次运行输出 0 条即收敛）。

## 六、与总装的接口

1. **注文不进主表**：注文走独立内容通道，不占 398 条条号，不改变正文对齐结论（只做了 T4 的 22 条提级/定性）。
2. **注文与独有重叠待裁决**：`最终版本包.独有` 1102 项中，按首十字精确命中计至少 **578** 项即本包已抽出的注文段。按任务书「发现注文误标写争议清单、不自改」的要求，本组**未改动**独有序，去留请总装裁决（争议 2）。
3. **核对口径**：注文不参与与宋本的字面比对；比对只对正文（`txt.cjk` 去括注后按字覆盖）。
