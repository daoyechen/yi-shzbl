## 三、执行步骤

1. 备料 → 转录 → 校验页锚（79 个）
2. 写 `spec.json`（原因枚举不得自创；`evid` 必须是原文）
3. `python3 -m shjkit.pkgbuild <本包目录>`
4. **本体裁专项**：`裁定工具/` 五步流水线 → 产出 `_工作/注文单元.json` 与 `交付/注文对照.md`（详见《清单》第四节）
5. 逐条核验 `交付/待复核.md`（本轮 0 条）
6. 填四件套（清单 / 索引 / 疑难 / SKILL）
7. `python3 -m shjkit.verify <本包目录>` → 全 ✅（12/12，2 警告见争议 4）
8. 交总装
