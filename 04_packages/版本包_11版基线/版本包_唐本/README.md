## 三、执行步骤（链序固定）

1. 备料 → 转录 → 校验页锚
2. 写 `spec.json`（原因枚举不得自创；`evid` 必须是原文）
3. `python3 -m shjkit.pkgbuild <本包目录>` ← **会删掉 `最终版本包.json`**
4. `python 工具/i1_cand.py` → `i2_pick.py` → `i3_decide.py`（句级窗口 + 裁定）
5. `python3 -m shjkit.overlay <本包目录>` ← 叠加 `交付/人工裁定.json`
6. `python 工具/i7_restore.py`（反推成套裁定）→ `i8_trim.py`（裁剪过长原文）
7. `python 工具/i4_indep.py`（T4）→ `i5_docs.py`（T3/T5/体例）→ `i6_docs.py`（清单/索引/SKILL/README）

8. `python3 -m shjkit.verify <本包目录>` → 12/12 全 ✅ 才交总装

> 3 与 5 之间不能跳步：`pkgbuild` 重写 `版本包.json` 时会删掉 `最终版本包.json`，只跑前段会丢光人工裁定。
