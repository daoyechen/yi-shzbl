# SKILL · 唐本 判读经验

> 本文件记**本版专属**的判读口径，供后续同类工作复用。不讲通用流程（通用流程见 `公共地基/SKILL.md`）。

---

## 一、本版是什么样的书

- **底本**：《备急千金要方》卷九「伤寒上」，影印见《伤寒论版本大全》第 309–368 页
- **版式**：按方分篇：太阳病用桂枝汤法、麻黄汤法、青龙汤法、柴胡汤法、承气汤法、陷胸汤法，另立阳明/少阳/太阴/少阴/厥阴「病状」与「伤寒宜忌」
- **属性**：节录本（选集），非全书；孙思邈「方证同条、比类相附」之改编本
- **校勘功能**：校宋本之「方证归类」；保存宋本未收之方与「宜忌」类条文

## 二、本版特有的坑（判条前必读）

1. 节录本，省略极多：字面相近不等于同一条，须整句对齐方可提级
2. 180 条本版作「胃中寒」，宋本作「胃家实」——《千金》与宋本的对文异读
3. 温病、风温、阳旦诸条本卷 0 见（另见《千金》卷九他篇）
4. 「伤寒宜忌」一篇合可/不可为一，与六经条重出 22 条

## 三、方法：句级窗口 + 三指标

1. **行级窗口不够。** 三版都存在「一行含多条」：唐本 一行内可并两三条。按行取窗，第二、三条必然被并进第一条。**必须先按 `。！？` 切句**（`；` 不切），再在句序列上取 1–8 句的连续窗口。
2. **窗口不能只取短窗口。** 短窗口能把 F1 刷满：曾出现「桂枝二越婢一汤」6 字窗口 F1=1.00。故窗口下限取 1 句、上限 8 句，按 F1 取 top6 去重，再由人裁定。
3. **三个指标一起看**：
   - `覆盖 = 命中字 / 宋本该条字数` —— 宋本这条有多少字见于本版；
   - `占比 = 命中字 / 本版窗口字数` —— 防「并进旁条」（窗口很长、只沾一点不算）；
   - `F1 = 几何平均` —— 两者都达标才算候选。
4. **置信由差异性质定，不由分数单定。** 差异全属 `{异体,通假,语序,省略,增字,衍字,同文}` → 高；含「异文」→ 中；分数太低 → 低。
5. **绝对命中字数门槛要按条长收敛。** 短条（如「少阳病欲解时，从寅至辰上」14 字）永远够不到 12 字门槛，门槛取 `min(12, L)` / `min(9, 0.7L)` / `min(7, 0.55L)`。
6. **一条正文只能被认领一次。** 同一 `(页, 文本[:24])` 被多条认领时，只留覆盖最高者，余者判「无」并在证据里写明「已判为宋本 N 条」。
7. **中低置信复核是「验既有对应」，不是重新海选。** 把引擎已配原文也放进候选，仅当它的 F1 高于新窗口时才优先——否则会把原本正确的对应判成「无」。

## 四、本版判条口径

- **节录本**：省略极多,字面相近不等于同一条;必须整句对齐,且该句在本版独立成段,方可提级
- **按方分篇**：太阳病用桂枝汤法/麻黄汤法/青龙汤法/柴胡汤法/承气汤法/陷胸汤法;一篇内可含宋本数篇之条
- **胃中寒**：180 条本版作「胃中寒」,宋本作「胃家实」——《千金》与宋本的对文异读,判「有·中置信」
- **只存一端**：宋本长条本版只留前半(如 48),余文不收:前半认领本版,整条判「无」并在证据里写清
- **已判邻条**：本版一段文字已判给邻近条号(如 51 的文字实为 52),本条即判「无」,不重复认领
- **伤寒宜忌**：合可/不可为一篇,与六经条重出 22 条;归篇按字符位置,不按篇名
