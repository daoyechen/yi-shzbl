## 三、执行步骤(可复现)

```bash
cd 公共地基/引擎
python3 -m shjkit.pkgbuild ../版本包_脉经本全卷      # 引擎 7 件 + 版本包.json
python3 -m shjkit.overlay  ../版本包_脉经本全卷      # 叠加 交付/人工裁定.json → 最终版本包.json
python3 -m shjkit.verify   ../版本包_脉经本全卷      # 12/12 ✅
```

> `交付/人工裁定.json` 由派发包内 `工具/t4.py` 依 `_工作/条级命中.json` 生成;
> 该 JSON 的页号已按十卷重编(旧页号 ≤49 者 +49)。**不要再手工加偏移**,脚本已幂等。
